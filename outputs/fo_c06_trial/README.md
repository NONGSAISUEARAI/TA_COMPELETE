# ผลลอง FO กับ ESTIMATE_C06_REV02.dwg

ทดลองวันที่ 3 พฤศจิกายน 2026 บน AutoCAD 2026 Core Console โดยอ่านไฟล์จาก `C:/TA/PPLINE CKST/C1-C2_Finishes-Reflected Ceiling Plan/PP17/CAD/ESTIMATE_C06_REV02.dwg` แล้วทำงานกับสำเนาแยก ผลในโฟลเดอร์นี้เป็นสำเนาทดสอบ ไม่ได้เขียนทับต้นฉบับ

## เรากำลังทำอะไร

สร้างเครื่องมือถอดพื้นที่ Overall ของชุดแผงฝ้า C06 จาก Block, Pline และเส้นที่เลือก โดยใช้รูปทรงชิ้นงานเป็นขอบ ข้ามบล็อกข้อมูล/สัญลักษณ์ตามรายการยกเว้น เติมรอยต่อระหว่างชิ้นให้ได้ Polyline ปิดหนึ่งเส้น แล้วแทรกบล็อกข้อมูลเดิม `facade_1_INFO` พร้อม Attribute `AREA`, `MAT`, `STATION`, `FLOOR`

ชื่อ `facade_1` เป็นชื่อ preset ของเครื่องมือ ส่วนชิ้นงานใน DWG นี้เป็นแผงฝ้า คำสั่ง FO ไม่สร้าง LENGTH Attribute แล้ว ส่วน MAT/STATION/FLOOR ยังว่างตาม preset และยังไม่ได้ดึงค่าจากบล็อกข้อมูลแผงมาใส่อัตโนมัติ

## สิ่งที่พบในไฟล์

- Model Space มีวัตถุระดับบน 2,080 ชิ้น รวม INSERT 1,485 ตัว และ LWPOLYLINE 377 เส้น มีกริด กรอบแบบ ข้อความ และข้อมูลแผงปะปนกัน
- พบบล็อกข้อมูลแผง `000_CKST-FAMELINE_CEILING06_CODE_PANEL` 690 ตัว นิยามบล็อกนี้มี TEXT 34 ตัว, ATTDEF 17 ตัว และ LWPOLYLINE 21 เส้น การไม่อ่าน TEXT/Attribute อย่างเดียวยังเหลือกราฟิก Polyline ของบล็อกนี้เข้าคำนวณ
- พบผล FO เดิมเป็น Outline 5 เส้น และ `facade_1_INFO` 4 ตัว
- การทดลองเลือกเป็นชุดแผงเฉพาะบริเวณ ไม่ได้นำกรอบแบบ/กริด/ทุกชุดงานมารวมเป็น Overall เดียว

ทั้งสองชุดใช้ `factor_area_ = 0.000001` แปลงพื้นที่หน่วยแบบ mm² เป็น m² และแสดงทศนิยม 2 ตำแหน่ง ใช้ Block Definition `facade_1_INFO` เดิม แทรก Reference ใหม่พร้อม 4 Attribute และไม่มี LENGTH Insert วัตถุต้นทางที่เลือกมีข้อมูล DXF ตรงกับก่อนรัน

ชุดแรกมีพื้นที่แผงแต่ละชิ้นรวมกัน **8.35486451 ตร.ม.** แต่พื้นที่ Outline Overall คือ **9.14321644 ตร.ม.** ต่างกัน **0.78835193 ตร.ม.** จากส่วนรอยต่อ/ช่องห่างที่ขอบรวมครอบเพิ่ม พื้นที่นี้จึงเป็นพื้นที่ภายในขอบ Overall ไม่ใช่ผลรวมพื้นที่วัสดุของแผงแต่ละชิ้น

เทียบชุดแรกด้วยรายการยกเว้นเดิมกับรายการที่เพิ่ม Code block:

| การทดลอง | บล็อกที่ข้าม | REGION รอบแรก | เวลารัน FO |
| --- | --- | --- | --- |
| A: preset เดิม | INFO 1 ตัว | 308 | 38.968 วินาที |
| B: เพิ่มชื่อ Code block | INFO 1 ตัว + Code 14 ตัว | 14 | 0.688 วินาที |

พื้นที่และจำนวนจุดยอดของชุดแรกเท่ากัน เพราะกราฟิก Code block ของชุดนี้อยู่ภายในแผง แต่การข้ามกราฟิกดังกล่าวลดงานคำนวณได้มาก เวลาข้างต้นเป็นการรันเทียบหนึ่งครั้งในเครื่องนี้ ไม่ใช่การรับประกันเวลาทุกรูปแบบ ชุดผสมใช้เวลา 1.328 วินาที

`tolerance_fo_ = 0.01` ยังเป็นค่าคลาดเคลื่อนทางเรขาคณิต ไม่ใช่ระยะสูงสุดสำหรับแยกชุดแผง โหมด OVERALL ยังเชื่อมวัตถุที่เลือกข้ามช่องว่างได้ จึงต้องเลือกชุดที่ต้องการถอดพื้นที่ให้ตรงงาน
