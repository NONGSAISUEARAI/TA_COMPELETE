# CAD Automation Portfolio

พอร์ตไทย/อังกฤษในรูปแบบคลังคำสั่ง โดยแต่ละรายการมีชื่อคำสั่ง คำอธิบาย และ GIF สาธิตจากการใช้งานจริง

ตอนนี้มีหน้าแรก HTML ตัวอย่าง โครงสร้างโฟลเดอร์ รายการคัดเลือก และรายงานวิเคราะห์ source ยังไม่ได้คัดลอก AutoLISP สำหรับแจกหรือเผยแพร่ผลงาน

## หน้าแรกตัวอย่าง

- `index.html` — หน้าแนะนำพอร์ต หมวดใช้งาน และผลงานที่กำลังคัดเลือก
- `css/home.css` และ `js/home.js` — รูปแบบ responsive, สลับ TH/EN, กรองหมวด และดูภาพรวมคำสั่ง
- `assets/images/home-preview.jpg` — ภาพหน้าแรกที่ตรวจจากเบราว์เซอร์

เปิด `index.html` ด้วยเบราว์เซอร์จากเครื่องได้โดยไม่ติดตั้ง dependencies ต้องเก็บไฟล์ CSS/JS ในตำแหน่งเดิม ภาพ Dynamic Properties เป็นภาพแนวคิด ไม่ใช่ GIF หรือผลทดสอบ CAD ชื่อ ประวัติ และช่องทางติดต่อผู้พัฒนายังรอข้อมูลจริง ไม่มี analytics หรือไฟล์ดาวน์โหลด AutoLISP ในหน้าแรกนี้

ตรวจตัวอย่างผ่าน HTTP ในเครื่อง: หน้าแรก/CSS/JS ตอบ 200, สลับภาษา, ภาพแนวคิด, category filter, empty category และ dialog ทำงาน ตรวจหน้าจอปกติและขนาดมือถือ 390×844 (พื้นที่เนื้อหา 375px เมื่อมี scrollbar) ไม่พบ horizontal overflow ที่ขนาดมือถือที่ตรวจ ไม่มี console error/warning ที่บันทึกได้ในรอบทดสอบนี้

## โครงสร้าง

```text
cad-automation-portfolio/
  README.md
  docs/
    command-selection.md     รายการใช้ / พักไว้ / ไม่ใช้
  data/                      ข้อมูลคำสั่งสำหรับหน้ารวม
  assets/
    gifs/                    GIF สาธิตคำสั่ง
    images/                  ภาพก่อน–หลังและภาพประกอบ
  css/                       รูปแบบหน้าตาเว็บ
  js/                        การทำงานของหน้าเว็บ
  downloads/
    lisp/                    เฉพาะไฟล์ที่คัดเลือกและอนุญาตให้ดาวน์โหลด
```

`index.html` อยู่ที่รากโฟลเดอร์นี้แล้ว หน้าแยกของแต่ละหมวดและคำสั่งยังไม่ได้สร้าง ไม่ต้องใส่ไฟล์ต้นฉบับทั้งหมดลงในเว็บ

## ลำดับงาน

1. เติมรายการใน `docs/command-selection.md` และเลือกคำสั่งสำหรับหน้าแรก
2. ใส่คำอธิบายไทย/อังกฤษและข้อมูลคำสั่งที่คัดเลือกใน `data/`
3. เตรียม GIF จริงและภาพประกอบให้ตรงกับแต่ละคำสั่ง
4. เขียน `index.html` เป็นหน้ารวมคำสั่งตามหมวด
