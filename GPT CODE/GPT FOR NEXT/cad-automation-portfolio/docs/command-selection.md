# รายการคัดเลือกคำสั่ง / Command Selection

เอกสารคัดเลือกคำสั่งร่วมกันก่อนเริ่มเขียนหน้าเว็บ ขณะนี้ตัดกลุ่ม PPLINE ออกจากพอร์ตรอบนี้แล้ว และเลือกพิจารณาหมวด Block / Dynamic Block ต่อ ส่วนรายคำสั่งยังรอคัดเลือก

## สถานะ

- **ใช้** — นำไปแสดงในพอร์ต
- **พักไว้** — รอข้อมูล สื่อสาธิต การตรวจโค้ด หรือการยืนยันสิทธิ์
- **ไม่ใช้** — ไม่แสดงในพอร์ตรอบนี้; ไม่มีการลบโค้ดต้นฉบับ

## ตารางคัดเลือก

หนึ่งรายการต่อหนึ่งชื่อคำสั่ง ถ้ามีหลาย definition ให้ระบุเลขบรรทัด/เวอร์ชันที่เลือก

## มติคัดเลือกตามกลุ่ม

| กลุ่มคำสั่ง | สถานะ | เหตุผล | วันที่ |
|---|---|---|---|
| PPLINE | ไม่ใช้ในพอร์ตรอบนี้ | เป็นคำสั่งเฉพาะทาง ตามการคัดเลือกของผู้ใช้ | 11 ตุลาคม 2026 |
| Block / Dynamic Block | พิจารณาต่อ — ยังไม่ยืนยันรายคำสั่ง | ผู้ใช้เลือกหมวดนี้เป็นหัวข้อถัดไป; เน้นคำสั่งที่ใช้กับ block ทั่วไป | 11 ตุลาคม 2026 |

ใช้มตินี้กับ command (`c:`) ที่มี `PPLINE` ในชื่อ โดยไม่สนตัวพิมพ์ รวมชื่อแบบ `temp_PPLINE...` ด้วย ตัวอย่างเช่น `PPLINE_300hk_ins300hk`, `PPLINE_CKST_ADD_CODE_TO_PANEL_300sort` และ `PPLINE-CKST_CSDupdate_` ยังไม่ต้องเตรียมหน้ารายละเอียดหรือ GIF ให้กลุ่มนี้ในรอบปัจจุบัน

มตินี้ไม่ครอบคลุมคำสั่งอื่นทั้งหมวด Panel / Ceiling / CSD โดยอัตโนมัติ และไม่ตัด shared helper ที่คำสั่งทั่วไปอาจใช้ร่วมกันออกจาก dependency การตัดออกจากพอร์ตไม่เปลี่ยนหรือลบ source เดิม และกลับมาพิจารณาได้ในรอบถัดไป

## รายการรายคำสั่ง

ข้อเสนอสำหรับหมวดที่กำลังพิจารณา: [Block / Dynamic Block](block-dynamic-review.md) รายการในเอกสารนั้นยังเป็นข้อเสนอ ไม่ใช่การอนุมัติให้แสดงหรือเผยแพร่ source ทุกคำสั่ง

ผลตรวจเชิงลึก: [Block source audit](block-static-audit.md) แยกคุณค่าพอร์ตจากความพร้อมใช้งาน พร้อมหลักฐานความเสี่ยงใน Replacement/Scale/Rebuild และ test plan ข้อเสนอเหล่านี้ยังไม่เปลี่ยนเป็นมติใช้/ไม่ใช้รายคำสั่งจนกว่าผู้ใช้จะเลือก

| ชื่อคำสั่งจริง | ชื่อผลงานไทย / English | หมวด | ใช้ / พักไว้ / ไม่ใช้ | GIF / ภาพ | เผยแพร่ source ได้หรือไม่ | เหตุผล / จุดที่ต้องตรวจ |

## ข้อมูลที่จะใช้ในหน้ารวม

- ชื่อผลงานไทย/อังกฤษ
- ชื่อที่พิมพ์เรียกจริงใน AutoCAD
- หมวดและคำอธิบายสั้น
- GIF หรือภาพสาธิตจริง
- สถานะการตรวจและข้อจำกัดที่พบ
- เครดิตและลิงก์ดาวน์โหลด เฉพาะรายการที่อนุญาต
