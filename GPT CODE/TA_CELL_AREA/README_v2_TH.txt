TA_CELL_AREA v2.5 — Block Units + Width/Length Filter + Attribute Block

APPLOAD ไฟล์ TA_CELL_AREA_v2.lsp แล้วต้องเห็นข้อความ Loaded TA_CELL_AREA v2.5
พิมพ์ TCAA2 เพื่อทำอัตโนมัติ (TCAA ใช้โหมดเดียวกัน)

PRESETTING อยู่บนสุดของไฟล์
แก้ค่า บันทึกไฟล์ แล้ว APPLOAD อีกครั้งเพื่อใช้ค่าใหม่
- tca:prompt = T: ถาม Input พร้อมแสดงค่าที่ตั้งไว้ กด Enter เพื่อรับค่านั้น
- tca:prompt = nil: เลือกเส้นแล้วใช้ Presetting ทั้งหมดทันที ไม่ถามหน่วย/Area/ข้อมูลอีก
- tca:units: Drawing / Millimeters / Meters (เริ่มต้น Millimeters)
- tca:filter: Size (ค่าเริ่มต้น) ใช้ความกว้าง/ยาวขั้นต่ำ หรือ Area ใช้เกณฑ์พื้นที่เดิม
- tca:min-width: ความกว้างขั้นต่ำ = ด้านสั้น ใช้หน่วยแบบ (เริ่มต้น 0.0)
- tca:min-length: ความยาวขั้นต่ำ = ด้านยาว ใช้หน่วยแบบ (เริ่มต้น 0.0)
- tca:min-area: ใช้เฉพาะโหมด Area เป็นหน่วยผลลัพธ์ ต้องมากกว่าเท่านั้น (เริ่มต้น 0.0)
- tca:scale: สเกลบล็อก (เริ่มต้น 25.0)
- tca:mat / tca:station / tca:floor: ค่าร่วมทุกช่อง (เริ่มต้นสตริงว่าง)
- tca:block: ชื่อบล็อก (เริ่มต้น facade_1_INFO ตามไฟล์อ้างอิง)
- tca:block-units: หน่วยนิยามบล็อก ATT เริ่มต้น 4 = Millimeters (mm)
  รหัส 9 หมายถึง Mils (0.001 นิ้ว) ซึ่งเป็นคนละหน่วยกับมิลลิเมตร
- tca:precision: ทศนิยม AREA ตั้งแต่ 0 ถึง 8 (เริ่มต้น 2)
- tca:layer-boundary / tca:layer-info: เลเยอร์ขอบและบล็อกข้อมูล
- tca:color-boundary / tca:color-info: สี ACI ของเลเยอร์ที่สร้างใหม่ (เริ่มต้น 3 และ 2)
- tca:style / tca:spacing: สไตล์และระยะห่างแถว ใช้เฉพาะตอนสร้างนิยามบล็อกใหม่
- tca:offset: ระยะเลื่อนบล็อก X/Y ตาม UCS ปัจจุบัน หน่วยแบบ ไม่คูณสเกล

ค่าที่แก้ตอนตอบ Input จะจำไว้จนกว่าจะ APPLOAD ไฟล์อีกครั้ง
การ APPLOAD จะอ่าน Presetting จากหัวไฟล์ใหม่ รวมทั้ง MAT/STATION/FLOOR
นิยามบล็อกและเลเยอร์เดิมใน DWG จะคงรูปแบบและสีเดิมไว้
หน่วยของนิยามบล็อก ATT จะอัปเดตตาม tca:block-units
ตัวอย่างใช้ค่าที่ตั้งไว้โดยไม่ถามซ้ำ:
(setq tca:prompt nil)
(setq tca:filter "Size")
(setq tca:min-width 500.0)
(setq tca:min-length 2000.0)
(setq tca:mat "ALUMINIUM 3MM")
(setq tca:station "ST-01")
(setq tca:floor "L02")

ลำดับต่อไปนี้ใช้เมื่อ tca:prompt เป็น T:

1. เลือกเฉพาะเส้นกริด LINE / POLYLINE / XLINE แล้ว Enter
2. เลือก Millimeters ถ้าแบบวาดเป็นมิลลิเมตรและต้องการผลเป็น ตร.ม.
   หรือเลือก Meters ถ้าวาดเป็นเมตร ส่วน Drawing รายงานหน่วยแบบยกกำลังสอง
3. โหมด Size: กำหนดความกว้างขั้นต่ำ แล้วกำหนดความยาวขั้นต่ำ ใช้หน่วยแบบ
   ต้องผ่านทั้งสองค่า จึงสร้างขอบและบล็อกข้อมูล ขนาดเท่ากับเกณฑ์ถือว่าผ่าน
   ถ้าแบบใช้มิลลิเมตร ให้ใส่ขนาดเป็นมิลลิเมตร แม้ผล AREA จะรายงานเป็น ตร.ม.
   โหมด Area: กำหนดเกณฑ์พื้นที่ตามหน่วยผลลัพธ์ ต้องมากกว่าเท่านั้น เท่ากันไม่ผ่าน
4. เมื่อมีช่องผ่านเงื่อนไข จึงกำหนดสเกลบล็อก (เริ่มต้น 25 เหมือนไฟล์อ้างอิง)
   นิยามเริ่มต้นใช้ข้อความสูง 1 จึงได้ความสูงข้อความเท่ากับสเกลที่ใส่
   ถ้าไม่มีช่องผ่านเงื่อนไข คำสั่งจะจบโดยไม่ถามสเกลหรือข้อมูล Attribute
5. กรอก MAT, STATION, FLOOR ครั้งเดียว ใช้กับทุกช่องที่ผ่านเงื่อนไข
   กด Enter เพื่อใช้ค่าล่าสุดใน session
6. โปรแกรมสร้างขอบสีเขียวและแทรก Attribute Block เอง ไม่ต้องคลิกภายในช่อง

บล็อกข้อมูลใช้ชื่อ facade_1_INFO ตาม TA_FACADE_OUTLINE.lsp
แท็ก AREA คำนวณอัตโนมัติตามหน่วยที่เลือก แสดงทศนิยมตาม tca:precision (เริ่มต้น 2 เหมือนไฟล์อ้างอิง)
แท็ก MAT / STATION / FLOOR รับค่าจากผู้ใช้ ใช้ชุดเดียวกันตลอดคำสั่งหนึ่งรอบ
การคัดกรอง Area ใช้ค่าจริงก่อนปัดทศนิยม ต้องมากกว่าเกณฑ์เท่านั้น
เงื่อนไข Size ของ TCAA/TCAA2 ใช้ขนาด Bounding Box ตาม UCS ของช่องนั้น
ด้านสั้นเป็นความกว้าง ด้านยาวเป็นความยาว ไม่ขึ้นกับการวางแนวนอน/ตั้ง
ช่องรูปเว้าใช้ขนาดกรอบครอบรวม ไม่ได้วัดความแคบของแต่ละช่วงภายในช่อง
โหมด Size ใช้แทนเกณฑ์ Area ไม่ได้นำสองเกณฑ์มารวมกัน
ถ้ามีบล็อกนี้อยู่ใน DWG แล้ว จะใช้รูปแบบเดิม แก้เฉพาะหน่วยของนิยามบล็อก
ไม่แก้รูปทรง/ตำแหน่ง ATTDEF หรือค่าของบล็อกที่แทรกไว้ก่อน
Attribute เพิ่มเติมในนิยามเดิมจะใช้ค่าเริ่มต้นของนิยามนั้น
ถ้าไม่มีนิยาม จะสร้างชื่อเดียวกันและรูปแบบ 4 แถวตามไฟล์อ้างอิง
หากชื่อเดิมไม่มีแท็กที่แก้ไขได้ครบ AREA/MAT/STATION/FLOOR จะรายงานข้อผิดพลาด
ไม่ต้องโหลด TA_FACADE_OUTLINE.lsp ก่อน และโปรแกรมนี้ไม่แก้ไฟล์อ้างอิง

โหมดอัตโนมัติ v2 วิเคราะห์เส้นจริงและจุดตัดเพื่อไล่ตามขอบช่อง
ไม่ใช้คำสั่ง BOUNDARY ไม่ต้องมีจุดสีแดง และไม่ต้องเชื่อมเส้นเดิม
LINE และ POLYLINE ใช้ช่วงเส้นจริง ส่วน XLINE คิดเป็นเส้นยาวไม่สิ้นสุด
POLYLINE จะเปิดหรือปิดก็ได้ แต่ทุกท่อนต้องเป็นเส้นตรง
ช่องเป็นรูปเว้าหรือช่องสี่เหลี่ยมที่เกิดจากเส้นตัดกันได้

เส้นต้องอยู่ในระนาบเดียวกันและขนานแกน X/Y ของ UCS ปัจจุบัน
หากกริดเอียง ให้ตั้ง UCS ให้ตรงกับกริดก่อน
ขอบที่มีช่องว่างจริงจะไม่สร้างพื้นที่ปิดให้
เหมาะสำหรับเครือข่ายกริด ไม่มีการหักพื้นที่เกาะ/กรอบซ้อนภายในช่อง
พื้นที่ขั้นต่ำใช้ข้ามช่องเล็กระหว่างเส้นคู่ และใช้หน่วยเดียวกับผลลัพธ์
จำนวนตำแหน่งกริดจำกัดที่ 10000 จุดต่อครั้ง ให้เลือกแบ่งพื้นที่หากเกิน

ผลลัพธ์ขอบอยู่ที่เลเยอร์ TA-CELL-BOUNDARY
บล็อกข้อมูลอยู่ที่เลเยอร์ TA-FACADE-INFO เหมือนไฟล์อ้างอิง
พื้นที่รวมแสดงที่ Command Line ดูย้อนหลังด้วย F2
กด U หลังคำสั่งจบเพื่อยกเลิกผลลัพธ์รอบนั้น
TCA ยังเป็นโหมดคลิกภายในช่อง ส่วน TCAP ใช้ POINT/CIRCLE เป็นจุดอ้างอิง

การตรวจสอบ v2
ทดสอบใน AutoCAD 2025 Core Console ด้วยวัตถุ LINE/PLINE/XLINE จริง
ไม่มีการแทนฟังก์ชันสร้างขอบด้วยฟังก์ชันจำลองในชุดทดสอบ v2
ตรวจการสร้างขอบและข้อความจริง พื้นที่จาก curve จริง ตัวกรองพื้นที่ขั้นต่ำ
ช่องเว้า เส้นยื่น ช่องขอบรั่ว เส้นซ้อน การรักษาเส้นต้นฉบับ และคืนค่าตัวแปร
ยังไม่ได้ใช้ DWG ของผู้ใช้ในการทดสอบ

ตรวจเพิ่มใน v2.2: สร้าง Attribute Block จริง 4 ช่อง, AREA ถูกต้อง,
MAT/STATION/FLOOR เหมือนกันทุกช่อง, ใช้นิยามจากไฟล์อ้างอิงที่ปรับตำแหน่ง
และจุดฐานไว้แล้วโดยไม่แก้นิยาม, เก็บค่าเริ่มต้นของแท็กเพิ่มเติม และคืนค่า
ATTREQ/ATTDIA/ANGBASE/ANGDIR/AUNITS/CLAYER หลังแทรกบล็อก

ตรวจเพิ่มใน v2.3: โหมดใช้ Presetting โดยไม่ถาม Input, กด Enter รับค่าเริ่มต้น
ทั้ง 6 รายการ, ค่า MAT/STATION/FLOOR, สเกล, Offset, บล็อกและเลเยอร์ที่ตั้งเอง,
สีเลเยอร์ใหม่ และระยะห่างแถวของนิยามบล็อกใหม่

ตรวจเพิ่มใน v2.4: ค่าเท่ากับความกว้าง/ยาวขั้นต่ำผ่านได้ ต้องผ่านทั้งสองมิติ
สี่เหลี่ยม 500x2000 และ 2000x500 ผ่านเกณฑ์เดียวกัน แต่ 499x2000 ไม่ผ่าน
ทดสอบการสร้าง Attribute Block จริงและคำนวณ AREA ให้ช่องที่ผ่านแล้ว

หน่วยบล็อก ATT ใน v2.5
- ตั้งเป็น Millimeters (mm) ทั้งบล็อกที่สร้างใหม่และนิยามเดิมที่คำสั่งนำมาใช้
- APPLOAD แล้วใช้ TCAUNIT เพื่ออัปเดตหน่วยบล็อกเดิมทันที โดยไม่ต้องสร้างช่องใหม่
- TCAUNIT ใช้ชื่อ tca:block และหน่วย tca:block-units ตาม Presetting
- ไม่เปลี่ยนหน่วยของ DWG ถาวร และไม่ปรับสเกล/ตำแหน่งของบล็อกที่แทรกไว้แล้ว
- ระหว่างแทรกข้อมูลใหม่ โปรแกรมป้องกันการแปลงหน่วยอัตโนมัติซ้ำซ้อน
  เพื่อให้สเกลบล็อกเป็นค่าที่กำหนดไว้ แล้วคืนค่า INSUNITS ของ DWG ทันที
- ทดสอบหน่วย BLOCK_RECORD จริงใน AutoCAD 2025 แล้ว ทั้งนิยามใหม่และเดิม
