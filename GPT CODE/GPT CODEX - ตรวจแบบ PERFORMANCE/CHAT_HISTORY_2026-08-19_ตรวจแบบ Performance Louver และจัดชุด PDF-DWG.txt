- Drawing Title: ชื่อแบบใน Title Block ด้านล่างขวา เช่น

- ต้องสนใจคำ ตัวเลข ช่วงหมายเลข และเครื่องหมายที่มีความหมาย เช่น &, -, SHEET 1, DETAIL 1-6

======================================================================
3. วิธีแยกประเภทแบบ
======================================================================

ต้องแยกประเภทของแต่ละ View ก่อนตรวจ Scale แม้ในแผ่นเดียวจะมีหลายประเภทแบบ

- Plan: มองจากด้านบน มีแนว Grid, ระยะตามแนวราบ และการจัดวางแผง
- Elevation: รูปด้าน เห็นระดับอาคารและแนวแผงในแนวดิ่ง
- Section: รูปตัด เห็นชั้นวัสดุ โครงสร้าง และองค์ประกอบที่ถูกตัด
- Detail: รูปขยายจุดต่อหรือชิ้นส่วน มีมิติขนาดเล็กและรายละเอียดสกรู/Bracket

ถ้าไม่มีคำกำกับ Heading ให้พิจารณาจากลักษณะทางสถาปัตยกรรมและรายละเอียดของ View ก่อนตัดสิน Scale

======================================================================
4. กติกา Scale ที่ยืนยันแล้ว
======================================================================

4.1 Plan และ Elevation

- Heading Scale = 1:100
- Title Block = A1 1:50 / A3 1:100

4.2 Section

- Heading Scale หลัก = 1:40, 1:50 หรือ 1:60
- หากพบ Scale อื่นที่ผิดแปลกจากชุดนี้ ต้องแจ้งผู้ใช้
- Title Block ต้องสัมพันธ์กับ Heading Scale
  ตัวอย่าง Heading 1:50 = A1 1:25 / A3 1:50

4.3 Detail

- Heading Scale = 1:10
- Title Block = A1 1:5 / A3 1:10

4.4 หลักการอ่าน Title Block

- Heading Scale อ้างอิงจากกระดาษ A3
- ค่า A1 จะมีตัวส่วนครึ่งหนึ่งของ A3
- ตัวอย่าง:
  Heading 1:100 -> A1 1:50 / A3 1:100
  Heading 1:50  -> A1 1:25 / A3 1:50
  Heading 1:10  -> A1 1:5  / A3 1:10

======================================================================
5. รายการตรวจในแต่ละแผ่น
======================================================================

1) ยืนยันว่าเป็นไฟล์ฉบับล่าสุดจาก Last Modified
2) ตรวจ Drawing No. ใน Title Block ให้ตรงกับชื่อไฟล์ PDF
3) แยกประเภท View: Plan, Elevation, Section หรือ Detail
4) ตรวจ Heading Scale ของทุก View ตามประเภทแบบ
5) ตรวจค่า A1 และ A3 ใน Title Block ให้สัมพันธ์กับ Heading Scale
6) ตรวจข้อความหลัง PERFORMANCE LOUVER ให้ตรงกับ Drawing Title
7) ตรวจเลขวงกลมหรือ View Number ให้ตรงกับชื่อ View
8) ตรวจจำนวน Detail/Section ที่ปรากฏจริงให้ตรงกับช่วงเลขใน Drawing Title
9) ตรวจหาเส้นหรือวัตถุแปลกปลอม
10) เรนเดอร์ PDF ฉบับล่าสุดเป็นภาพเพื่อตรวจด้วยสายตา ไม่พึ่ง Text Extraction เพียงอย่างเดียว

======================================================================
6. สิ่งแปลกปลอมที่ต้องแจ้ง
======================================================================

- เส้นแนวนอนยาวเหนือ Title Block แบบที่ผู้ใช้เคยชี้ด้วยลูกศรสีเขียว ถือเป็นเส้นแปลกปลอมและไม่ควรมี
- ต้องแยกเส้นดังกล่าวออกจากเส้นกรอบ Title Block, เส้น Dimension, เส้น Ground และเส้นประกอบแบบที่ถูกต้อง
- หากพบวัตถุหรือ Scale ที่ไม่เหมือนรูปอื่นในชุดเดียวกัน ต้องแจ้ง แม้ข้อความ Heading และ Drawing Title จะตรงกัน

======================================================================
7. วิธีตรวจ PDF ที่พัฒนาขึ้น
======================================================================

- ตรวจ Timestamp ก่อนทุกครั้ง เพื่อป้องกันการใช้ผลจากไฟล์เก่า
- ลบเฉพาะไฟล์ภาพ/ข้อความชั่วคราวของแผ่นที่มีการอัปเดต แล้วเรนเดอร์ใหม่
- ใช้ Text Extraction เพื่อค้นหา Heading, Drawing Title, Scale, A1, A3 และ Drawing No.
- ใช้ภาพ Render ตรวจตำแหน่งจริง เลขวงกลม เครื่องหมาย &, เส้นแปลกปลอม และความผิดปกติทางกราฟิก
- ตรวจซ้ำเฉพาะแผ่นที่เคยผิดหลังมีการแก้ไข
- ห้ามแก้ PDF หรือ DWG เมื่อคำสั่งคือ "ตรวจ" เท่านั้น
