FOLDER MAP — PERFORMANCE LOUVERS

Naming rule
- Every folder name carries the full preceding path as its prefix.
- The preceding path is enclosed in square brackets: [PREFIX]_CURRENT_FOLDER.
- Date folders use the format [FULL_PREFIX]_yyyymmdd.
