# SHW v2.1 — แสดงเส้น Hidden ใต้ Wipeout

สร้างเส้นประเฉพาะช่วงของวัตถุที่ซ้อนอยู่ในพื้นที่ Hatch หรือ Wipeout ตามที่เลือก โดยเก็บต้นฉบับไว้เหมือนเดิม ถ้าเลือก Block เส้นที่สร้างใหม่จะอยู่ใน Model Space / Paper Space ด้านนอก Block ไม่แก้ Block Definition และไม่กระทบ Block ตัวอื่น

## ติดตั้งและใช้งาน

1. เปิด AutoCAD บน Windows แล้วใช้ `APPLOAD` โหลด `TA_SHOW_HIDDEN.lsp`
2. พิมพ์ `SHW` หรือ `SHOWHIDDEN`
3. เลือกเส้น / Polyline / วงกลม / เส้นโค้ง / Block ที่ต้องการแสดงส่วนที่ถูกบัง แล้วกด Enter
4. เลือก Wipeout หรือ Block ที่มี Wipeout ซึ่งบังวัตถุ แล้วกด Enter ถ้าเลือก Block ที่มีทั้งเส้นต้นทางและ Wipeout ไว้ตั้งแต่ข้อ 3 สามารถกด Enter เพื่อค้นหา Wipeout ภายใน Block ที่เลือกได้เลย
5. กด Enter เพื่อปรับสเกลเส้นประอัตโนมัติให้เหมาะกับความยาวแต่ละช่วง หรือระบุ Linetype Scale เอง

ผลลัพธ์อยู่ในเลเยอร์ `TA-HIDDEN-OVERLAY` สีแดง ใช้ชนิดเส้น `HIDDEN` และถูกย้ายมาด้านหน้า โหมด Auto คำนวณจากความยาวช่วงเส้นจริง ชนิดเส้นที่โหลด และ `LTSCALE` โดยไม่แก้ `LTSCALE` ของแบบ

`SHW` ใช้เฉพาะ Wipeout เป็นพื้นที่บัง เพื่อไม่สับสนกับ Hatch ลายวัสดุภายในบล็อก หากต้องการใช้ Hatch เป็นพื้นที่บังโดยตั้งใจ ให้ใช้คำสั่ง `SHWHATCH` แทน

หากไม่พบ Wipeout คำสั่งจะแจ้งให้เลือกบล็อกที่มีตัวบังเพิ่ม จะไม่นำ Hatch มาใช้แทนโดยอัตโนมัติ

## โหลดทับรุ่นก่อนหน้า

ใช้ `APPLOAD` โหลดไฟล์นี้ซ้ำในแบบที่ต้องการใช้งาน แล้วตรวจว่าขึ้นข้อความ `TA_SHOW_HIDDEN v2.1 loaded` ก่อนสั่งใหม่ ลบเส้นแดงผลลัพธ์รอบเก่าที่ไม่ต้องการก่อน เพื่อไม่ให้ซ้อนกับผลลัพธ์ใหม่

รุ่น 2.1 แก้การแปลงแกน Y ของขอบ Wipeout จากพิกัดภาพเป็นพิกัดในแบบ สูตรเดิมทำให้ขอบเอียงกลับด้านและเลื่อนตำแหน่ง โดยเฉพาะ Wipeout ที่กว้างกว่าสูง รุ่นนี้อ้างอิงความสูงของภาพ Wipeout จริงและทิศทางเวกเตอร์ของภาพ จึงรองรับการหมุนและกลับด้านด้วย

ใช้ `UNDO` หนึ่งครั้งเพื่อย้อนผลการสร้างเส้นทั้งรอบ สามารถเลือกเส้นใหม่เพื่อลบหรือปรับสีและสเกลภายหลังได้

## ขอบเขตการทำงาน

- คำนวณพื้นที่ซ้อนกันในมุมมองแปลน WCS XY ไม่ขึ้นกับ UCS ที่ตั้งไว้ และเก็บระดับ Z ของเส้นต้นทาง
- รองรับ Block ปกติ รวมถึง Block ซ้อน หมุน กลับด้าน และย่อขยาย โดยทำงานผ่านสำเนาชั่วคราวเท่านั้น บล็อกสเกลไม่เท่ากันใช้วิธีคำนวณตำแหน่งวัตถุย่อยตามลำดับบล็อกโดยตรง ไม่จำเป็นต้อง Explode บล็อกนั้นได้
- LINE / ARC / CIRCLE และส่วนเส้นตรงหรือส่วนโค้งของ Polyline สร้างผลลัพธ์เป็นเส้นหรือส่วนโค้งจริง
- ELLIPSE / SPLINE สร้างเส้น Polyline ประมาณรูปด้วยค่าความละเอียดเริ่มต้น `0.05` หน่วยแบบ ปรับได้ด้วย `(setq *TA:SHW-Chord* 0.01)` ก่อนสั่งงาน
- ส่วนโค้งที่ถูกบล็อกย่อขยายแต่ละแกนไม่เท่ากันจะกลายเป็นรูปวงรีตามรูปทรงจริง ส่วนขอบ Hatch ที่ต้องแปลงด้วยวิธีนี้ใช้ค่าประมาณ `0.001` หน่วยแบบ
- เคารพช่องว่างด้านในและ Island Style ของ Hatch และรวมพื้นที่ของตัวบังหลายตัวเข้าด้วยกัน ไม่สร้างเส้นซ้ำจากพื้นที่บังที่ซ้อนกัน
- ข้ามข้อความ Attribute, Dimension, Hatch และวัตถุอื่นที่ไม่ใช่เส้นเมื่ออ่านภายใน Block
- รุ่นนี้ใช้กับวัตถุ 2D ที่ขนานกับระนาบ WCS XY ยังไม่รองรับ Xref, XCLIP, MINSERT, Surface หรือ Solid 3D
- อ่าน Polyline ตามแนวแกนกลาง ไม่คำนวณความกว้างเส้น Thickness หรือ Lineweight เป็นพื้นที่

คำสั่งใช้ตัวบังที่ผู้ใช้เลือกเป็นเกณฑ์ ไม่ตรวจสอบ Draw Order เดิมหรือสี/ความโปร่งใสของ Hatch แบบอัตโนมัติ และเส้นที่สร้างเป็นผลลัพธ์ ณ เวลานั้น หากย้ายวัตถุต้นทางหรือพื้นที่บัง ต้องลบเส้นผลลัพธ์เดิมแล้วสั่งใหม่

## การทดสอบ

`tests/TA_SHOW_HIDDEN_tests.lsp` เป็นชุดทดสอบใน AutoCAD ตัวเต็มกับแบบว่างแยกต่างหาก ตรวจสอบความยาวเส้น ผลลัพธ์นอก Block การคงต้นฉบับ การเก็บกวาดสำเนาชั่วคราว ขอบโค้ง ช่องว่างใน Hatch และ WIPEOUT จริง

ชุดทดสอบเดิมมี 32 ข้อใน `tests/results.txt` ส่วนกรณีเพิ่มของ v2 อยู่ใน `tests/TA_SHOW_HIDDEN_v2_tests.lsp` และผลใน `tests/results-v2.txt` ซึ่งตรวจบล็อกที่มีทั้ง Hatch และ Wipeout การสเกลหลายแกน และเส้นประช่วงสั้น

ผลชุดทดสอบของรุ่น 2.0 บน AutoCAD 2026: **32 ข้อเดิม + 14 ข้อเพิ่ม ผ่านทั้งหมด** เป็นผลของแบบทดสอบจำลอง

รุ่น 2.1 เพิ่ม `tests/TA_SHOW_HIDDEN_v21_tests.lsp` ซึ่งให้ AutoCAD สร้าง Wipeout จริงจากรูปทรงที่ทราบพิกัด แล้วตรวจว่าฟังก์ชันในไฟล์หลักอ่านจุดกลับมาตรงกับรูปทรงเดิม รวมถึงจุดตัดเส้นแนวนอน ขอบเว้า การหมุน การกลับด้าน และพิกัดระดับเดียวกับแบบงาน ผลก่อนแก้คือ **ผ่าน 3 / ไม่ผ่าน 10** และหลังแก้คือ **ผ่าน 13 / ไม่ผ่าน 0** ดู `tests/results-v21-before.txt` และ `tests/results-v21.txt`

ชุดพิกัดนี้รันได้ใน Core Console โดยใช้ `node tests/prepare-core-tests.mjs` เพื่อเตรียมฟังก์ชันจากไฟล์ผลิตจริง แล้วรัน `tests/run-core.scr` การสร้างเส้นและอ่านบล็อกของคำสั่ง SHW ยังต้องใช้ AutoCAD ตัวเต็มที่รองรับ ActiveX

`tests/run.scr` ระบุโฟลเดอร์ของโปรเจกต์บนเครื่องนี้ หากย้ายโฟลเดอร์ให้แก้ตัวแปร `sht-root` ก่อนรัน ชุดทดสอบต้องใช้ AutoCAD ตัวเต็มที่รองรับ ActiveX ไม่ใช้ Core Console
