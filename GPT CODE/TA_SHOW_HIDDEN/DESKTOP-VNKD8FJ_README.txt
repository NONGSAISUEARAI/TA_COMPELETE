4. วิธีใช้งาน
1) พิมพ์ SHW หรือ SHOWHIDDEN สำหรับ WIPEOUT
   ถ้าต้องการใช้ HATCH เป็นพื้นที่บัง ให้พิมพ์ SHWHATCH
2) เลือกเส้น / Polyline / วงกลม / เส้นโค้ง / Block ต้นทางทั้งหมดที่ต้องการ
   แสดงส่วนที่ถูกบัง แล้วกด Enter
3) เลือก WIPEOUT หรือ Block ที่มี WIPEOUT ซึ่งเป็นตัวบัง แล้วกด Enter
   สำหรับ SHWHATCH ให้เลือก HATCH หรือ Block ที่มี HATCH
   ถ้าตัวบังอยู่ภายใน Block ที่เลือกในขั้น 2 แล้ว สามารถกด Enter โดยไม่เลือกเพิ่ม
4) กด Enter เพื่อใช้สเกลเส้นประ Auto หรือระบุค่าบวกด้วยตนเอง

SHW ใช้ WIPEOUT เท่านั้น ไม่เปลี่ยนไปใช้ Hatch ลายวัสดุโดยอัตโนมัติ
หากไม่พบ WIPEOUT ให้เลือกตัวบังหรือ Block ที่มีตัวบังเพิ่มในขั้น 3
วัตถุต้นทางและตัวบังต้องอยู่ใน Model Space / Paper Space ที่กำลังทำงานเดียวกัน

5. ผลลัพธ์
เลเยอร์: TA-HIDDEN-OVERLAY
สี: แดง
ชนิดเส้น: HIDDEN
ตำแหน่ง: ด้านนอก Block และย้ายมาอยู่ด้านหน้าด้วย Draw Order
Auto คำนวณสเกลจากความยาวช่วง ชนิดเส้นที่โหลด และ LTSCALE ของแบบ
คำสั่งไม่เปลี่ยน LTSCALE ของแบบ
ใช้ UNDO หนึ่งครั้งเพื่อย้อนการสร้างทั้งรอบ
เลือกผลลัพธ์ใหม่เพื่อปรับสี สเกล หรือลบได้ตามปกติ
ถ้าย้ายต้นทางหรือตัวบัง ต้องลบผลลัพธ์เดิมแล้วรันใหม่

6. สิ่งที่แก้ในรุ่น 2.1
อาการที่พบ: เส้นแดงเริ่มก่อนถึงขอบ WIPEOUT เอียง และมีบางส่วนเลยพื้นที่บังจริง
สาเหตุที่ยืนยันใน AutoCAD: การแปลงพิกัดแกน Y ของภาพ WIPEOUT ผิดทิศทาง
ทำให้ขอบเอียงกลับด้านและเลื่อนตำแหน่ง โดยเฉพาะพื้นที่กว้างกว่าสูง
แก้สูตรให้อ้างอิงความสูงภาพและทิศทางเวกเตอร์ U/V จริง
ชุดทดสอบพิกัดครอบคลุมขอบเอียง รูปเว้า หมุน กลับด้าน และพิกัดขนาดใหญ่

7. ขอบเขตและข้อจำกัด
- คำนวณใน WCS XY สำหรับวัตถุ 2D ที่ขนานกับระนาบนี้ และคืนระดับ Z ของต้นทาง
- รองรับ Block ซ้อน หมุน กลับด้าน และย่อขยาย รวมถึงสเกลแต่ละแกนไม่เท่ากัน
  โดยใช้สำเนาชั่วคราวหรืออ่านวัตถุย่อยตามการแปลงพิกัดของ Block
- LINE / ARC / CIRCLE และชิ้นส่วนเส้นตรงหรือส่วนโค้งของ Polyline ใช้รูปทรงจริง
- ELLIPSE / SPLINE สร้าง Polyline ประมาณรูป ความละเอียดเริ่มต้น 0.05 หน่วยแบบ
  ปรับก่อนรันด้วย (setq *TA:SHW-Chord* 0.01)
- ส่วนโค้งใน Block ที่สเกลไม่เท่ากันอาจกลายเป็นวงรี และผลลัพธ์วงรีใช้ Polyline
- ขอบ Hatch ที่ต้องแปลงแบบสเกลไม่เท่ากันใช้ค่าประมาณ 0.001 หน่วยแบบ
- รองรับช่องว่างและ Island Style ของ Hatch รวมพื้นที่ตัวบังที่ซ้อนกัน
- ข้ามข้อความ Attribute, Dimension, Hatch และวัตถุที่ไม่ใช่เส้นเมื่ออ่านต้นทาง
- ไม่รองรับ Xref, XCLIP, MINSERT, Surface, Solid 3D และวัตถุเอียงออกจาก WCS XY
- อ่าน Polyline ตามแนวแกนกลาง ไม่คำนวณ Width, Thickness หรือ Lineweight เป็นพื้นที่
- ใช้ตัวบังที่เลือกเป็นเกณฑ์ ไม่วิเคราะห์ Draw Order เดิม สี หรือความโปร่งใสของ Hatch
- เส้นผลลัพธ์ไม่เชื่อมโยงกับต้นทางแบบอัปเดตอัตโนมัติ

8. แก้ปัญหาเบื้องต้น
ไม่มีเส้นใหม่: ตรวจว่าต้นทางตัดพื้นที่บังจริงและเลือกตัวบังถูกต้อง
เส้นยังเพี้ยนเหมือนเดิม: ตรวจข้อความ v2.1 loaded และลบผลลัพธ์เก่าก่อนรันใหม่
เส้นประดูทึบ: ลอง Auto และตรวจชนิดเส้น HIDDEN ที่โหลดกับสเกลการแสดงผลของแบบ
โหลด HIDDEN ไม่ได้: ใช้ LINETYPE โหลด HIDDEN จากไฟล์ LIN แล้วรันใหม่
เลเยอร์ผลลัพธ์มีปัญหา: TA-HIDDEN-OVERLAY ต้องเปิด ไม่ Freeze ไม่ Lock และใช้ HIDDEN
รูปทรงหรือชนิดวัตถุไม่รองรับ: ดูข้อจำกัดในข้อ 7 และข้อความบน Command Line
ต้องการข้อมูล error สำหรับพัฒนาต่อ: อ่านตัวแปร TA:SHW-LastError หลังรัน
