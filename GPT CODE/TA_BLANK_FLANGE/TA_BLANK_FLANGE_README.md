# TA_BLANK_FLANGE

สร้างขอบนอก Blank จากแผ่นต้นแบบ โดยเพิ่มปีกพับเฉพาะขอบที่เลือก

ตำแหน่งชุดโค้ด: `C:\Users\tawan.t\Documents\GitHub\TA_COMPELETE\GPT CODE\TA_BLANK_FLANGE`

## ใช้งาน

1. `APPLOAD` ไฟล์ `TA_BLANK_FLANGE.lsp` แล้วเรียก `TA_BLANK_FLANGE`
2. เลือกแผ่นต้นแบบด้วย `entsel` ต้องเป็น **LWPOLYLINE ปิด ขอบตรง ไม่มีส่วนโค้ง**
3. คลิก Point 1 และ Point 2 ที่ปลายขอบเดียวกัน เลือกย้อนทิศหรือข้ามไปทำขอบอื่นได้
4. ใส่ระยะปีก **X** ซึ่งวัดตั้งฉากกับขอบแผ่น ตามหน่วยในแบบ
5. ใส่ **Ang1** อ้างอิงจาก Point 1 ไป Point 2 แล้วหมุนออกนอกแผ่น
6. ใส่ **Ang2** อ้างอิงจาก Point 2 ไป Point 1 แล้วหมุนออกนอกแผ่น
7. ทำซ้ำกับขอบอื่น แล้วกด Enter ที่คำถาม Point 1 เพื่อจบ

มุมกรอกเป็นองศา: `45/45` ปาดปลายทั้งสองเข้าหากัน, `90/90` ปลายตั้งฉาก
อนุญาตมุมมากกว่า 0 แต่น้อยกว่า 180 องศา โดยไม่อ้างอิง ANGBASE/ANGDIR ของแบบ
ขอบที่มีมุมหักต้องเลือกแยกเป็นแต่ละขอบตรง ไม่ลากลัดมุม

ค่า X, Ang1 และ Ang2 จำค่าล่าสุดแยกกัน โดยแสดงใน `<...>` และกด Enter เพื่อใช้ค่าเดิม
เรียกคำสั่งใหม่ในแบบเดิม หรือโหลด LSP ซ้ำ ค่าที่จำไว้ยังอยู่จนกว่าจะปิดแบบนั้น
การจำนี้ใช้ตัวแปร Global `*TA:BF:Width*`, `*TA:BF:Ang1*`, `*TA:BF:Ang2*`
ซึ่งไม่ได้ประกาศหลัง `/` ค่าเริ่มต้นจาก Preset ใช้เมื่อยังไม่มีค่าที่จำไว้เท่านั้น
Undo/Esc ย้อนการสร้างเส้น แต่คงค่าตัวเลขล่าสุดที่รับไว้แล้วสำหรับการเรียกครั้งหน้า

## ผลลัพธ์และการแก้ระหว่างทำงาน

- ได้ Polyline ปิดเส้นเดียว และแสดงผลใหม่ทุกครั้งที่เพิ่มปีก
- เพิ่ม **เส้นแนวพับเป็น Polyline เปิด** ตามแนว Point 1–Point 2 เดิม เฉพาะขอบที่ทำปีกสำเร็จ
- ขอบที่ไม่ได้ทำปีกไม่มีเส้นแนวพับเพิ่ม แต่แผ่นต้นแบบยังคงอยู่ครบ
- เส้นแนวพับแยกวัตถุจากขอบ Blank และตั้งสี/เลเยอร์/ชนิดเส้นได้อิสระ
- ช่วงที่ไม่ได้ทำปีกจะตาม Vertex เดิมทุกจุด แล้วเชื่อมต่อเป็นขอบนอกเดียวกัน
- เก็บแผ่นต้นแบบไว้เป็นแนวอ้างอิง/แนวพับ
- เลือกขอบเดิมซ้ำเพื่อเปลี่ยนระยะหรือมุมของปีกนั้น
- พิมพ์ `Undo` ที่คำถาม Point 1 เพื่อย้อนการแก้ครั้งล่าสุด ทั้งขอบ Blank และเส้นแนวพับ
- Enter ที่คำถาม Point 2 ยกเลิกเฉพาะการเลือกคู่นั้น
- Esc ยกเลิกงานรอบนี้และลบเส้น Blank พร้อมเส้นแนวพับที่เพิ่งสร้าง ส่วนต้นแบบยังอยู่
- หลังจบ ใช้ Undo ของ AutoCAD ย้อนทั้งคำสั่งได้
- ถ้าปลายปีกตัดกัน หรือเส้นรอบรูปตัด/ซ้อนตัวเอง โปรแกรมจะปฏิเสธการแก้ครั้งนั้นและเก็บผลก่อนหน้า

## Preset

แก้ใน `TA:BF:Preset_` ด้านบนไฟล์ แล้วโหลดไฟล์ใหม่:

| ค่า | ค่าเริ่มต้น |
|---|---|
| Layer | `TA_BLANK_SIZE` |
| Color | `3` สีเขียวแบบ ACI; `256` คือ ByLayer |
| Linetype | `Continuous` |
| BendLayer | `TA_BEND_LINE` — เลเยอร์เส้นแนวพับ |
| BendColor | `7` — ขาว/ดำตามพื้นหลัง |
| BendLinetype | `HIDDEN` — เส้นประแสดงแนวพับ |
| BendLinetypeScale | `1.0` — สเกลชนิดเส้นเฉพาะเส้นแนวพับ |
| Width | `25.0` |
| Ang1 / Ang2 | `45.0` / `45.0` |

ถ้าต้องการกลับไปใช้ค่าเริ่มต้นจาก Preset ให้ล้างเฉพาะค่าที่จำไว้:

```lisp
(setq *TA:BF:Width* nil *TA:BF:Ang1* nil *TA:BF:Ang2* nil)
```

ถ้าเลเยอร์ยังไม่มี โปรแกรมจะสร้างให้ ถ้ามีแล้วจะใช้เลเยอร์นั้นโดยไม่เปลี่ยนค่าของเลเยอร์เดิม
เลเยอร์ผลลัพธ์ต้องเปิด ไม่ Freeze และไม่ Lock
ชนิดเส้นใช้จากแบบก่อน ถ้ายังไม่มีจะลองโหลดจาก `acadiso.lin` หรือ `acad.lin`
ค่าทั้งสามกำหนดที่วัตถุผลลัพธ์ จึงแก้ผ่าน Properties ภายหลังได้
Preset ของแนวพับใช้ชื่อขึ้นต้น `Bend` แยกจาก Preset ขอบ Blank
ถ้าเส้นประดูทึบหรือถี่เกินไป ปรับ `BendLinetypeScale` แล้วโหลดไฟล์และสร้างใหม่
เส้นที่สร้างไว้ก่อนแก้ Preset สามารถปรับ Linetype scale ผ่าน Properties ได้

## ขอบเขตการคำนวณ

นี่คือขอบคลี่แบบเรขาคณิตตามระยะ X ที่ป้อน **ยังไม่คำนวณ Bend Allowance,
Bend Deduction, K-factor, ความหนาแผ่น หรือรอยบากผ่อนมุม**
จึงต้องป้อน X เป็นระยะคลี่ที่ต้องการอยู่แล้ว ไม่ใช่รับรองขนาดตัดจากความสูงปีกหลังพับ

รองรับ UCS ที่หมุน/ย้ายตำแหน่ง และคง OCS/ระนาบ/ระดับของแผ่นต้นแบบ
สร้างใน Model หรือ Paper Space ของต้นแบบ
