## สถานะข้อมูล

- มี 2 หมวดหลัก: PJ25-031 และ MRT PURPLE LINE STANDARD DRAWING C1
- PJ25-031 ครอบหัวข้อ PP17, PP18, PP19, PP20 ตามลำดับ แต่ละ PP ใช้โครงสร้างเดียวกัน: C04 C05 C08 C09 รวมเป็นพื้นที่เดียว มี 6 งาน และ C10 มี 3 งาน รวมงานระดับสุดท้าย 36 รายการ
- PP แต่ละหัวข้อมี 11 แถวข้างใต้ (2 หัวข้อพื้นที่ + 9 งาน) รวม PP ทั้งสี่หัวข้อเป็น 48 แถวใต้ PJ25-031
- รายการใหม่นี้แทนโครงสร้าง PP เดิมตามข้อความผู้ใช้วันที่ 9 พฤศจิกายน 2026 จึงไม่มี C02-C03, C09 แยก และชุดขั้นตอน SUBMIT DWG/ขอราคา/FG / ราคา/SOOM เดิมใน PP สำเนาก่อนปรับอยู่ใน backups
- คง id ของ PP17–PP20 เมื่อเปลี่ยนเป็น section, คง id หัวข้อ C04 C05 C08 (เปลี่ยนชื่อเป็น C04 C05 C08 C09), C10 และ PART DWG ใต้ C10 งานใหม่มี id แยกตาม PP
- MRT PURPLE LINE STANDARD DRAWING C1 ยังคงมีหัวข้อ C02–C10 ตามลำดับ 9 แถว เป็น section ไม่มีขั้นตอนย่อย ข้อมูลและไฟล์ประกอบเดิมคงอยู่ครบ: 6 รายการผูกโฟลเดอร์ เลือกไว้รวม 14 ไฟล์
- รวม 57 แถวย่อย หรือ 59 แถวเมื่อรวม 2 หมวดหลัก งานจริง 36 รายการ ไม่นับหัวข้อจัดกลุ่มซ้ำ
- วันเริ่ม/จบ ผู้รับผิดชอบ และความก้าวหน้ายังไม่ระบุ ไม่สมมติวันที่ ผลงาน หรือราคา ช่องว่างไม่ได้หมายถึงความก้าวหน้า 0% ที่ยืนยันแล้ว
- วันที่รายงานคงเป็น 30 ตุลาคม 2026 ตามข้อมูลที่บันทึกเดิม

## Rev02: ช่องข้อมูลแบบและ Plan / Actual

อ้างอิงไฟล์ `Program & Actual Drawing Schedul By Tawan 09-11-26.xlsx` ในโฟลเดอร์โปรเจ็กต์ ชีต `Programm Database` หัวคอลัมน์ A4:P4 โดยไม่แก้ไข Excel ต้นฉบับ ตอนเพิ่มช่องรับข้อมูลคงรายการงานเดิม ไม่ได้นำแถว Excel มาแทนโครงสร้าง ต่อมาจัดโครงสร้าง PJ25-031 ตามข้อความผู้ใช้โดยตรง รายการล่าสุดอยู่ด้านบน เส้น Tree และความสามารถของโปรแกรมคงเดิม

| ช่องใน Excel | ช่องใน Master Schedule |
| --- | --- |
| PJ | รหัสโครงการ pjCode |
| Project Works | projectWorks |
| Group Drawing | drawingGroup (ข้อมูลแบบ แยกจากหัวข้อแม่ใน Tree) |
| Product | product |
| Description | ชื่องาน/หัวข้อเดิม name |
| ข้อมูลปัจจุบัน | currentInfo |

| Unit / Quantity | unit / quantity (ว่างเป็น null, 0 เป็นจำนวนที่ยืนยันแล้ว) |
| Status / Action | workStatus / action (แยกจากสถานะตามวันที่ที่ระบบคำนวณ) |

เพิ่มตามคำขอผู้ใช้: Actual เริ่ม–จบ actualStart/actualEnd แยกจาก Plan ไม่เติมวันที่จากเปอร์เซ็นต์งาน และไม่เติมเปอร์เซ็นต์จากวันที่จริง หัวข้อแม่และหมวดหลักกำหนดวันที่ Plan และ Actual เองแยกกัน หรือเลือกใช้วันที่จากงานย่อยของแต่ละชุดได้ actualDateMode เก็บ manual/auto แยกจาก dateMode ของ Plan เปลี่ยนวันที่หัวข้อแม่ไม่แก้วันที่งานลูก

- Plan แสดงแถบเฉดสีด้านบน Actual แสดงสีเต็มด้านล่าง ใช้วันที่ของแต่ละชุด รวมช่วงทั้งสองในปฏิทิน เว้นวันอาทิตย์เช่นเดิม
- Actual ระบุวันเพียงข้างเดียวแสดงจุดวันที่ที่ทราบ ไม่สร้างอีกข้างหรือจำนวนวัน Actual สรุปจากลูกแยกตรวจแต่ละข้าง วันเริ่มแสดงเมื่อทุกงานระดับสุดท้ายมีวันเริ่มจริง วันจบแสดงเมื่อทุกงานมีวันจบจริง
- ทั้งหน้าเพิ่ม/แก้ไขงานและหมวดหลักมีช่องแบบชุดเดียวกัน ช่องใหม่เว้นว่างได้ ไม่คัดลอกค่า TAWAN/ดำเนินการจาก Excel ไปใส่งานเดิมโดยอัตโนมัติ
- ตารางหลักเรียง WBS → PJ → Project Works → Group Drawing → Product → Description โดย 4 ช่องตามภาพซ่อนเป็นค่าเริ่มต้นและกด Hide / Unhide 4 ช่องได้ หน้าเพิ่ม/แก้ไขงานและหมวดหลักมีข้อมูลชุดนี้ก่อน Description และไม่มีคอลัมน์ Heading เพิ่ม เส้น Tree และตำแหน่งยึดคอลัมน์ Description ใช้ชื่อคอลัมน์จึงยังทำงานเมื่อย้ายลำดับช่อง
- ตารางใช้หัวคอลัมน์ Start / วันเริ่ม และ End / วันจบ ภายในแต่ละงานแสดง Plan แถวบนและ Actual แถวล่าง วันที่เริ่มทั้งสองชุดอยู่ใต้ Start วันที่จบทั้งสองชุดอยู่ใต้ End คอลัมน์ข้อมูลแบบเพิ่มเติมกด “ข้อมูลแบบ (Excel)” เพื่อแสดงได้โดยไม่แก้ข้อมูลหรือสั่ง Auto-save
- เปิดครั้งใหม่เป็น Viewer วันที่ สี ไฟล์ประกอบ และการบันทึกเดิมยังใช้ได้ ไฟล์ดาวน์โหลดสำเนาระบุชื่อ Rev02
- Excel มี 16 หัวคอลัมน์และยังไม่มีวันเริ่ม/จบงานใน L/M; M3 เป็นวันที่รายงานใน Excel จึงไม่ได้ถือเป็นวันที่งาน หรือเปลี่ยนวันรายงานที่ผู้ใช้บันทึกไว้เดิม

## ใช้งาน

1. เปิด `Master_Schedule.html` ด้วย Chrome หรือ Edge
2. เปิดดู ค้นหา กรอง ยุบ–ขยาย และดูตารางเต็มจอได้ใน Viewer
3. กดปลดล็อก Editor และใส่รหัส `123123` เพื่อแก้ข้อมูล
4. กด `+ ย่อย` ข้างแถวเพื่อเพิ่มระดับ หรือแก้ชื่อและเลือกหัวข้อแม่จากหน้าต่างแก้ไข
5. เว้นวันที่และผลงานได้ เมื่อได้รับข้อมูลให้กรอกที่งานย่อย หรือกรอกวันแผนของหัวข้อแม่เอง หัวข้อแม่กด “ใช้วันที่จากงานย่อย” เพื่อกลับไปสรุปวันอัตโนมัติได้ ส่วน % ผลงานยังคำนวณจากงานระดับสุดท้าย
6. เลือกบันทึก HTML หรือเชื่อมไฟล์เดิมก่อนเปิด Auto-save; ปุ่มบันทึกสำเนา HTML รวมโปรแกรมกับข้อมูลล่าสุดไว้ด้วยกัน

นับวันทำงานจันทร์–เสาร์ เว้นอาทิตย์ และวันเริ่ม/จบที่เลือกเป็นอาทิตย์จะเลื่อนไปจันทร์ การเปิดไฟล์ครั้งใหม่เริ่มเป็น Viewer และต้องเลือกหรือเชื่อมปลายทางบันทึกอีกครั้ง

## ครอบหัวข้อหลักเดิมด้วยหัวข้อใหม่

1. ปลดล็อก Editor แล้วกด + งานหลัก เพื่อสร้างหัวข้อใหม่ที่จะครอบ เช่น MRT PURPLE LINE
2. กดแก้ไขหัวข้อหลักเดิม เช่น PP17 แล้วเปิด “อยู่ใต้หัวข้อ” เลือกหัวข้อใหม่ หรือเลือกงานในระดับย่อยลงไปอีกได้ ตัวเลือกเป็นต้นไม้พร้อม WBS และค้นหาได้
3. ตรวจตำแหน่งในต้นไม้ตัวอย่าง แล้วกดบันทึกหัวข้อ หัวข้อหลักเดิมจะกลายเป็น section ใน tasks โดยใช้ id เดิม งานลูกทั้งหมดเปลี่ยนไปอยู่หมวดเดียวกับปลายทาง และลูกตรงเดิมอยู่ใต้ section นี้
4. วันที่ Plan/Actual สี metadata ขอบเขตงาน และไฟล์ประกอบยังอยู่กับรายการเดิม เลข WBS คำนวณใหม่ตามตำแหน่ง ส่วนงานระดับสุดท้ายไม่ถูกนับซ้ำ กดบันทึก HTML เพื่อเก็บโครงสร้างลงไฟล์

เลือก “เป็นหัวข้อหลัก (ระดับบนสุด)” เพื่อคงระดับเดิมในหน้าแก้ไขหมวด หรือสร้างหัวข้อใหม่เป็นระดับบนสุด การเลือกตำแหน่งและยกเลิกยังไม่เปลี่ยนข้อมูล ย้ายไปใต้ตัวเอง/ลูกตัวเองไม่ได้ และตรวจตำแหน่งซ้ำตอนบันทึก หน้าเพิ่มหัวข้อหลักสามารถเลือกหัวข้อแม่เพื่อสร้าง section ใหม่ไว้ข้างใต้ได้ด้วย หลังเปลี่ยนเป็นหัวข้อย่อยแล้วใช้หน้าแก้ไขงานย่อยตามปกติ (รวมช่องรายละเอียด / ขอบเขตงาน)

## Hide / Unhide 4 คอลัมน์

เปิดหน้ามาจะซ่อน PJ, Project Works, Group Drawing และ Product ในตาราง กด Unhide 4 ช่อง เพื่อแสดงคืน และกด Hide 4 ช่อง เพื่อซ่อนอีกครั้ง ใช้ได้ทั้ง Viewer/Editor แยกจาก checkbox ข้อมูลแบบ (Excel) ไม่ลบค่า ไม่แก้ state/dirty/Auto-save และเริ่มซ่อนสี่ช่องเสมอเมื่อเปิดหน้าใหม่ ช่องกรอกในหน้าแก้ไขยังใช้งานได้

## Export งานเป็น Excel

1. กด **Export Excel** ข้างปุ่มพิมพ์ ใช้ได้ทั้ง Viewer และ Editor โดยไม่ต้องเปิดเซิร์ฟเวอร์
2. เลือกทั้งโครงการหรือหมวดหลัก เช่น PJ25-031 ระบบส่งออกหัวข้อและงานลูกครบทุกระดับตามลำดับปัจจุบัน ไม่ตัดรายการตามการค้นหา ตัวกรอง หรือการยุบในหน้าจอ และส่งออกช่องที่ซ่อนไว้ด้วย
3. เลือกรวมปฏิทินรายวัน (Gantt) และช่วงวันที่ที่ต้องการ ค่าเริ่มต้นครอบคลุมวันรายงานกับวัน Plan/Actual ของหมวดนั้น เริ่มจันทร์–จบอาทิตย์ อย่างน้อย 4 สัปดาห์ หรือเอาเครื่องหมายออกเพื่อส่งออกเฉพาะตารางข้อมูล
4. กด **ดาวน์โหลด Excel** จะได้ไฟล์ .xlsx จริง ใช้งานได้ออฟไลน์ ไม่พึ่งไฟล์ต้นแบบภายนอกหรือไลบรารีบนอินเทอร์เน็ต และไม่เปลี่ยนข้อมูล/ฉบับร่าง/Auto-save

## Import CSV จาก Excel (ตำแหน่งตายตัว)

ปลดล็อก Editor แล้วกด **Import CSV** ข้างปุ่ม Export Excel การนำเข้าใช้ CSV UTF-8 ในเครื่อง ทำงานออฟไลน์ ไม่อัปโหลดไฟล์ ไม่ต้องเปิดเซิร์ฟเวอร์ และไม่ต้องติดตั้งไลบรารีเพิ่ม

1. หากเริ่มจากข้อมูลปัจจุบัน เลือกหมวดในหน้าต่าง Import แล้วกด **ดาวน์โหลด CSV จากงานปัจจุบัน** เพื่อกรอกข้อมูลใน Excel ค่าเริ่มต้นเตรียมเฉพาะ PJ25-031 เลือกทุกหมวดได้
2. หากเริ่มจาก Excel ต้นแบบ ให้ดาวน์โหลด **VBA สำหรับ Excel** เปิด Excel บน Windows กด Alt+F11 → File → Import File เลือก Export_MasterSchedule_CSV.bas จากนั้นกลับ Excel กด Alt+F8 → ExportMasterScheduleCSV → Run แล้วเลือกที่เก็บ CSV หากจะเก็บ VBA ไว้ใช้อีกให้บันทึกสำเนา workbook เป็น .xlsm
3. กลับ HTML เลือก CSV ตรวจรายชื่อและกด **ดูข้อมูลที่จะเปลี่ยน** เพื่อเทียบค่าก่อน/หลัง แล้วกด **ยืนยันนำเข้า** การกดเลือกไฟล์หรือปิด/ยกเลิกยังไม่เปลี่ยนข้อมูล
4. กด **บันทึก HTML** เพื่อเก็บข้อมูลที่ยืนยันแล้วลงไฟล์ การนำเข้าใช้ฉบับร่างและ Auto-save ตามการตั้งค่าปกติของโปรแกรม

ตำแหน่งล็อก A:P ตามหัวตารางตัวอย่างเดิม: A PJ, B Project Works, C Group Drawing, D Product, E Description, F ข้อมูลปัจจุบัน, G Man, H Unit, I Quantity, J Status, K Action, L Shop Drawing Start Date, M Shop Drawing End Date, N Shop Dwg. Approved, O Remark, P Duration เพิ่ม Q=WBS, R=Plan / Actual จำเป็นต่อการจับคู่ต้นไม้และชุดวันที่ และ S=Node Type (Group/Section/Task) เป็นตัวช่วยคงหัวข้อที่ยังไม่มีลูก CSV จาก VBA/โปรแกรมมีหัวตารางแถวแรก และรับแถว 4 สำหรับ CSV ที่บันทึกจาก Excel Export ของโปรแกรมด้วย ไม่ให้ลากจับคู่หรือสลับคอลัมน์ ถ้าหัวตารางไม่ตรงจะหยุดนำเข้า

- กรอกข้อมูลทั่วไปในแถว Plan ส่วนแถว Actual อ่านเฉพาะ L/M แยกเป็นวันเริ่ม/จบจริง P ไม่อ่านกลับเพราะคำนวณจำนวนวันทำงานจากวันที่ ไม่เปลี่ยน % ผลงาน วันที่รายงานโครงการ หรือกำหนดส่งมอบ
- **อัปเดตงานเดิม** จับคู่ด้วยชื่อและเส้นทางต้นไม้ครบ แม้ WBS ปัจจุบันย้ายลำดับไปแล้วก็ไม่เปลี่ยนลำดับกลับ ใช้ WBS+ชื่อ+PJ ที่ไม่กำกวมเป็นทางเลือกเฉพาะแถวที่ไม่มีเส้นทางครบ ถ้าชื่อ/เส้นทางซ้ำหรือหาไม่พบจะหยุดทั้งชุด ไม่ข้ามเงียบ ๆ และไม่เปลี่ยน id/parentId/groupId/ชื่อ/สี/ไฟล์แนบ/ขอบเขตงาน
- เริ่มต้นเว้นค่าว่างไว้โดยไม่ล้างข้อมูลเดิม ถ้าต้องการล้างให้ติ๊ก **ใช้ค่าว่างใน CSV ล้างช่องข้อมูลเดิมด้วย** อย่างชัดเจน ศูนย์ Quantity เป็นตัวเลขที่นำเข้าได้ ไม่ถือเป็นค่าว่าง
- **เพิ่มเป็นหมวดใหม่** สร้างหมวดที่ระบุชื่อและ id ใหม่ทั้งหมด เก็บหมวดเดิมไว้ หัวข้อจาก CSV จะอยู่ใต้หมวดใหม่ตาม WBS ต้องมีหัวข้อแม่ครบ Node Type คง Section แม้ยังไม่มีลูก ไม่คัดลอกไฟล์แนบหรือสีที่ไม่มีอยู่ใน CSV ให้เอง
- วันใช้ yyyy-mm-dd หรือ dd/mm/yyyy (ค.ศ.) วันเริ่ม/จบที่เป็นอาทิตย์เลื่อนไปจันทร์พร้อมแจ้งในหน้าตรวจ วันที่อนุมัติคงวันจริง วันที่หัวข้อแม่ที่แก้เองจะเป็น manual ของชุดนั้น ไม่เปลี่ยนวันที่ลูก ส่วนวันที่หัวข้อแม่ที่ยังเท่าเดิมคง auto ไว้
- VBA อ่านชีต Programm Database แถวหัวตาราง 4 คอลัมน์ A:P ถ้ามี Q/R จากโปรแกรมจะใช้ WBS และ Plan/Actual เดิม ถ้าเป็นต้นแบบเดิมจะสร้างหัวข้อ PJ และ WBS จาก IndentLevel ของ Description พร้อมส่งออก Plan โดยไม่สมมติ Actual และไม่บันทึกทับ workbook ต้นฉบับ ไฟล์ .bas ใช้ตัวอักษร ASCII และประกอบหัวภาษาไทยด้วย ChrW เพื่อกันปัญหารหัสภาษาใน VBA Editor
- WBS ใน CSV ที่เตรียมให้มีเครื่องหมาย ' นำหน้าเพื่อคงเป็นข้อความ เช่น 1.10 ไม่ให้ Excel ตัดเหลือ 1.1 ปล่อยเครื่องหมายนี้ไว้ โปรแกรมอ่านกลับเป็น WBS ปกติให้เอง ข้อความที่ขึ้นต้นเหมือนสูตรและ apostrophe จริงถูกส่งออกเป็นข้อความและอ่านคืนได้
- รับ UTF-8 เท่านั้น รองรับ comma/semicolon, ข้อความมีเครื่องหมายคำพูด/comma/ขึ้นบรรทัดใหม่ ขนาดสูงสุด 10 MB / 20,000 รายการ / 40,000 แถวข้อมูล Plan–Actual
- ถ้าตารางเปลี่ยนหลังตรวจต้องกดตรวจใหม่ เมื่อกลับ Viewer หรือปิดหน้าต่าง จะยกเลิกข้อมูลที่เตรียมไว้ รวมผลอ่านไฟล์ที่กลับมาช้า การยืนยันเท่านั้นที่เปลี่ยน state/draft และไม่เปลี่ยนข้อมูลใน HTML จนกว่าจะบันทึก

ไฟล์ VBA อยู่ที่ Export_MasterSchedule_CSV.bas และฝังใน HTML ให้ดาวน์โหลดได้ด้วย ตัวอย่าง CSV จากข้อมูลจริงอยู่ที่ outputs/csv-import/Master_Schedule_PJ25-031_Template.csv (ไม่เติมวันที่หรือผู้รับผิดชอบ) รอบนี้ตรวจการนำเข้าแบบจำลองแล้ว ยังไม่ได้รัน VBA ใน Microsoft Excel จริง

## ย้ายลำดับรายการ

- ปลดล็อก Editor แล้วคลิกเลข WBS ของรายการที่จะย้าย เลขต้นทางจะติดสี และรายการปลายทางที่ย้ายไปได้จะแสดงกรอบ
- คลิกเลข WBS ปลายทางที่อยู่ภายใต้หัวข้อแม่เดียวกัน เลือก “วางก่อนรายการปลายทาง” หรือ “วางหลังรายการปลายทาง” แล้วกด “ย้ายมาที่นี่” หมวด PP ย้ายระหว่างหมวดหลัก งานย่อยย้ายภายใน groupId/parentId เดียวกัน ไม่มีปุ่มลูกศรขึ้น–ลงแยกใต้ WBS อีกแล้ว
- การเลือกต้นทาง/ปลายทางยังไม่เปลี่ยนข้อมูล กด Esc ปิดหน้าต่าง กดยกเลิก หรือคลิกเลขต้นทางซ้ำเพื่อเลิกย้าย ใช้ Enter/Space กับเลข WBS ผ่านแป้นพิมพ์ได้
- หัวข้อที่มีลูกย้ายพร้อมลูกทุกระดับ เลข WBS และเส้นต้นไม้ปรับตามลำดับใหม่ รหัส วันที่ ความก้าวหน้า สี และไฟล์ประกอบของแต่ละงานคงเดิม
- เมื่อกรองหรือค้นหา การวางก่อน/หลังอ้างอิงลำดับทั้งหมด งานที่ซ่อนอยู่ยังรักษาลำดับของตัวเอง การยุบ–ขยายไม่เปลี่ยนลำดับ บันทึก HTML เพื่อเก็บลำดับลงไฟล์ และยังเริ่มเป็น Viewer เมื่อเปิดใหม่
- หากต้องการเปลี่ยนหัวข้อแม่หรือย้ายข้ามหมวด ใช้ช่องหัวข้องานหลักและ “อยู่ใต้งาน” ในหน้าแก้ไข

ลำดับ PP17–PP20 และรายการในส่วนด้านบนเป็นลำดับปัจจุบันใน HTML ผู้ใช้สามารถเปลี่ยนลำดับเองผ่านการคลิกเลข WBS ได้

## วางที่อยู่โฟลเดอร์และเปิดไฟล์ในเครื่อง

1. ดับเบิลคลิก Open_Master_Schedule.cmd เพื่อเปิดหน้า Master Schedule ผ่านตัวช่วยบนเครื่อง โปรแกรมจะใช้ Master_Schedule.html ในโฟลเดอร์เดียวกัน และเปิดที่ http://127.0.0.1:48731/ หากตัวช่วยเปิดอยู่แล้วจะใช้ตัวเดิม
2. ปลดล็อก Editor เปิดแก้ไขงาน แล้วกดดูรายการไฟล์ วางที่อยู่ เช่น C:\TA\PP17\C03 หรือ file:///C:/TA/PP17/C03 ลงในช่องที่อยู่ รายการจะอ่านเองหลังหยุดพิมพ์ประมาณครึ่งวินาที หรือกด Enter อ่านทันที ไม่ต้องกดเลือกโฟลเดอร์ในโหมดนี้
3. ติ๊กไฟล์ทีละรายการ ทั้งหน้า หรือทั้งหมดที่ตรงตัวกรอง แล้วปิดรายการได้เลย การเลือกจะกลับไปหน้าแก้ไขงานโดยอัตโนมัติ กดบันทึกงานแล้วบันทึก HTML เพื่อเก็บลงไฟล์ หากยกเลิกหน้าแก้ไข งานที่บันทึกไว้เดิมยังคงอยู่
4. คลิกชื่อไฟล์ในหน้ารายการหรือใต้ชื่องานในตารางหลัก เพื่อเปิดด้วยโปรแกรมที่ Windows กำหนด เช่น PDF หรือ DWG ต้องมีไฟล์จริงและโปรแกรมที่เปิดชนิดนั้นได้ Viewer เปิดเอกสารที่บันทึกไว้ได้ แต่เปลี่ยนโฟลเดอร์/ติ๊กเลือกต้องผ่าน Editor
5. มีตัวกรองชื่อ นามสกุล โฟลเดอร์ย่อย และเฉพาะที่เลือก เรียงชื่อ/ขนาด/วันแก้ไขได้ แสดงหน้าละ 100 ไฟล์
6. “ไฟล์ที่เลือก” เยื้องไปทางขวาหนึ่งระดับเท่างานลูก และใช้ลูกศรยุบ–ขยายที่แนวเดียวกับลูกศรของหัวข้อย่อย ตารางหลักเริ่มยุบรายการไฟล์ใต้แต่ละงาน คลิก “ไฟล์ที่เลือก N / ทั้งหมด” เพื่อขยายหรือยุบ แยกจากการยุบหัวข้องาน ใช้ได้ทั้ง Viewer และ Editor เมื่อขยายแสดงชื่อที่เลือก 5 รายการแรกซึ่งกดเปิดเอกสารได้ และมีปุ่มดูรายการทั้งหมดหรือดูที่เลือกทั้งหมด สถานะยุบ–ขยายคงอยู่ระหว่างค้นหา กรอง หรือวาดตารางใหม่ในหน้าที่เปิดอยู่ โดยไม่เปลี่ยนข้อมูล/ฉบับร่าง และเริ่มยุบเมื่อเปิดหน้าใหม่

ตัวช่วยอ่านชื่อ ขนาด วันแก้ไข และตำแหน่งย่อย ไม่เก็บเนื้อหาเอกสารลง HTML รายการและ selected ถูกเก็บใน task.fileCatalog โดย source เป็น local หรือ picker อ่านใหม่คงการเลือกตาม relative path ของโฟลเดอร์เดิม แจ้งไฟล์ที่หาย และไม่ย้ายผลอ่านที่กลับมาล่าช้าไปใส่อีกงาน รองรับที่อยู่ไดรฟ์ UNC และ file URL จำกัด 20,000 ไฟล์ ข้าม junction/symlink ในโฟลเดอร์ลูก และแจ้งหากอ่านไม่ครบ ไฟล์คำสั่ง/ตัวติดตั้ง/shortcut ไม่เปิดผ่านตาราง

HTML ยังเปิดตรงจากไฟล์แบบเดิมได้โดยไม่ใช้ตัวช่วย แต่การอ่านไฟล์ต้องใช้ตัวเลือกโฟลเดอร์ที่เบราว์เซอร์อนุญาต การวางที่อยู่เพื่ออ่านทันทีและการเปิดเอกสารด้วยโปรแกรมใน Windows ใช้โหมด Open_Master_Schedule.cmd ตัวช่วยไม่ได้เพิ่มรายการเริ่มพร้อม Windows และไม่รับการเชื่อมต่อจากเครื่องอื่น โทเคนเชื่อมต่ออยู่ในหน่วยความจำ ไม่ติดไปกับ snapshot HTML

เมื่อคัดลอกไปใช้เครื่องอื่น ให้เก็บไฟล์ HTML และตัวช่วยทั้งสองไฟล์ไว้โฟลเดอร์เดียวกัน ที่อยู่เอกสารต้องมีอยู่บนเครื่องปลายทาง หากเปิดหน้าเก่าและมีข้อมูลใหม่ที่ยังไม่ลง HTML ให้บันทึกสำเนาคนละชื่อก่อนเปิดโค้ดล่าสุดเพื่อผสานข้อมูล

## วันแผนของหัวข้อแม่

- Editor แก้ช่องวันเริ่ม–จบของหัวข้อแม่ได้ เช่น งาน 1.2.2 แบบแผ่น Varies
- เมื่อกรอกวันเอง จะเก็บเป็นช่วงแผนของหัวข้อนั้น และคงไว้หลังบันทึก เปิดไฟล์ใหม่ หรือแก้วันที่ของงานลูก
- วันแผนของหัวข้อแม่แยกจากวันงานย่อย และยังไม่นับหัวข้อแม่ซ้ำในความก้าวหน้ารวม
- ปุ่ม “ใช้วันที่จากงานย่อย” เปลี่ยนกลับเป็นวันเริ่มต่ำสุดและวันจบสูงสุดของงานระดับสุดท้าย เมื่อข้อมูลลูกครบ
- หากใช้วันแผนแบบกำหนดเอง สามารถเว้นวันข้างใดข้างหนึ่งหรือเว้นทั้งคู่ได้ การล้างช่องในโหมดกำหนดเองไม่ถือเป็นการเลือกสรุปอัตโนมัติ
- วันเริ่มหรือจบที่ตรงอาทิตย์ยังเลื่อนไปจันทร์ และช่วงวันต้องไม่กลับด้าน

1. ปลดล็อก Editor แล้วกดแก้ไขงานหรือหมวดหลัก

## รูปแบบการแสดงผล

- Dark Mode สำหรับหน้าหลัก ตาราง หน้าต่างเพิ่มหรือแก้ไข และหน้าต่างยืนยันลบงาน
