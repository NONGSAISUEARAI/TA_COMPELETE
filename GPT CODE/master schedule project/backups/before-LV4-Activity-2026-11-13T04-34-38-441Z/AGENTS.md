# แนวทางทำงานกับ Master Schedule

## ไฟล์และข้อมูลอ้างอิง

- ไฟล์ใช้งานหลักคือ `Master_Schedule.html` เป็น HTML ไฟล์เดียว รวมหน้าตา โปรแกรม และข้อมูลไว้ด้วยกัน ไม่ต้องติดตั้งแพ็กเกจเพื่อใช้งาน
- อ่านข้อมูลปัจจุบันจาก `<script id="schedule-data" type="application/json">` ในไฟล์จริงก่อนแก้ทุกครั้ง และอ่าน `README.md` เพื่อดูรายการงานล่าสุด
- สำเนาใน `backups/` เป็นข้อมูลเก่าเพื่อกู้คืน ไม่ใช่ไฟล์ใช้งานหลัก อย่านำกลับมาแทนไฟล์ปัจจุบันโดยอัตโนมัติ
- ไม่ถือว่าฉบับร่างในเบราว์เซอร์ถูกบันทึกลง HTML แล้ว หากหน้าเก่ายังเปิดค้างและมีข้อมูลเพิ่ม ให้บันทึกสำเนาคนละชื่อเพื่อผสานข้อมูลกับโค้ดล่าสุด ไม่บันทึกหน้าเก่าทับไฟล์ที่เพิ่งแก้โค้ด

## กติกาที่ต้องรักษา

- ย้ายลำดับโดยคลิกเลข WBS ต้นทางแล้วคลิก WBS ปลายทางใน Editor เลือกวางก่อน/หลังและยืนยัน ไม่มีปุ่ม ↑/↓ แยกทุกแถว ต้นทางและปลายทางที่ใช้ได้แสดงสถานะชัดเจน รองรับ Enter/Space/Esc คลิกต้นทางซ้ำหรือยกเลิกไม่แก้ข้อมูล หมวดหลักย้ายใน groups งานย่อยย้ายภายใน groupId/parentId เดียวกันตามลำดับทั้งหมดรวมรายการที่ถูกกรอง ย้ายหัวข้อพร้อมลูกทุกระดับและจัด tasks เป็นลำดับต้นไม้ ไม่แก้ id/parentId/groupId หรือข้อมูลรายการ ตรวจสิทธิ์และความสัมพันธ์ซ้ำก่อนวาง อัปเดต WBS/เส้นต้นไม้ คงลำดับในฉบับร่าง Auto-save และ snapshot HTML และยกเลิกสถานะเลือกเมื่อกลับ Viewer
- โปรแกรมปัจจุบันเป็น Rev03 ตามคำขอวันที่ 9 พฤศจิกายน 2026 เพิ่มช่อง pjCode/projectWorks/drawingGroup/product/currentInfo/unit/quantity/workStatus/action/approvedDate/remark ตาม Excel Programm Database!A4:P4 โดยเก็บรายการงาน/ค่าเดิม ไม่สร้างลำดับงานจาก Excel แทน Tree ช่อง Description/Man/Duration ใช้ name/owner/จำนวนวันเดิม Quantity ว่างใช้ null แยกจาก 0 ที่ผู้ใช้ยืนยัน workStatus ไม่แทนสถานะตามวันที่ที่ระบบคำนวณ

- Gantt แยก Plan เฉดสีด้านบนและ Actual สีเต็มด้านล่าง คงสีประจำหัวข้อและสถานะเลยกำหนดจากกติกาเดิม ขอบเขตปฏิทินรวม Plan/Actual ทั้งงานและหัวข้อแม่ วันอาทิตย์ยังเลื่อนไปจันทร์และแถบเว้นอาทิตย์ ตารางเปิดข้อมูลแบบเพิ่มเติมได้ด้วย checkbox ข้อมูลแบบ (Excel) โดยไม่เปลี่ยนข้อมูล/Auto-save รักษา treeGuides เดิมทุกประการ
- รูปแบบวันที่ในตารางเป็นคอลัมน์ Start และ End แต่ละงานมี Plan แถวบน/Actual แถวล่าง วันที่ start/actualStart อยู่ใต้ Start และ end/actualEnd อยู่ใต้ End ข้อมูลวันที่และฟอร์มกรอกยังแยกชุดเดิม ส่วนป้ายไฟล์ของโครงการฐานข้อมูลวางข้างชื่อใน db-title-line เปิดรายการแล้วขึ้นบรรทัดเต็มได้ ส่วนหมวดเอกสารเก่ายังคงระยะเยื้องเดิม ไม่เปลี่ยน treeGuides
