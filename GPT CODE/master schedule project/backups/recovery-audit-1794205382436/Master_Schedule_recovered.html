นับวันทำงานจันทร์–เสาร์ · ไม่นับวันอาทิตย์ · เลื่อนตารางแนวนอนเพื่อดูวันถัดไป
วิธีเซฟไฟล์นี้ และใช้งานครั้งถัดไป

1. เปิดด้วย Chrome หรือ Edge แล้วกด บันทึก HTML เพื่อเลือกชื่อและปลายทาง ครั้งถัดไปจะบันทึกทับปลายทางนี้ได้
2. หากต้องการเซฟทับไฟล์ที่เปิดอยู่ กด เชื่อมไฟล์เดิม แล้วเลือกไฟล์ HTML ของโครงการนี้
3. เปิด Auto-save ลงไฟล์ เพื่อบันทึกหลังแก้ไขประมาณ 1.5 วินาที ขณะหน้านี้ยังเปิดอยู่
4. เมื่อเปิดใหม่ ข้อมูลจะอ่านจากไฟล์ และต้องเชื่อมปลายทางอีกครั้ง ปุ่ม บันทึกสำเนา HTML ดาวน์โหลดไฟล์ที่รวมข้อมูลล่าสุดไว้ พร้อมส่งต่อได้
โหมดใช้งาน: เปิดไฟล์จะเป็น Viewer กดปลดล็อก Editor เพื่อแก้ไข และล็อกกลับเมื่อเสร็จ โหมดนี้ช่วยป้องกันการแก้ไขโดยไม่ตั้งใจภายในหน้า HTML ไม่ใช่ระบบสิทธิ์ผู้ใช้บนเซิร์ฟเวอร์
ฉบับร่างในเบราว์เซอร์ช่วยกู้คืนบนเครื่องนี้ แต่ไม่ติดไปกับไฟล์ และอาจหายเมื่อเคลียร์ข้อมูลเบราว์เซอร์ หัวข้องานหลักใช้เก็บชื่อ ขอบเขตงาน พื้นที่ และผู้รับผิดชอบหลัก ส่วนงานย่อยเก็บรายละเอียดวันที่และผลงาน งานย่อยทุกแถวกด + ย่อย เพื่อแตกงานต่อได้ เช่น 1.1 → 1.1.1 → 1.1.1.1 และเลือกย้ายหัวข้อแม่ได้ในช่อง “อยู่ใต้งาน” หัวข้อที่มีงานย่อยกำหนดวันแผนเองได้ หรือเลือกใช้วันที่จากงานย่อย ส่วนผลงานยังสรุปจากงานระดับสุดท้าย ยอดรวมโครงการนับเฉพาะงานระดับสุดท้ายเพื่อไม่ให้นับซ้ำ กราฟนี้เป็นแผนงานแบบกำหนดวันที่เอง ยังไม่คำนวณงานต่อเนื่องหรือเส้นทางวิกฤตอัตโนมัติ
