# CUTTING_LIST — V0 (all cutting) และ V1 (แยก PP)

ทั้งสองเวอร์ชันเป็นฟังก์ชัน VBA คืนรายงานรวม 4 หมวดเหมือนเดิม: SUMMARY REPORT, Target used list, Item used list และ CUTTING PLAN ไม่มีการแยกรายงานเป็นบล็อกของแต่ละ PP

## เลือกเวอร์ชัน

| เวอร์ชัน | ไฟล์นำเข้า | ชื่อฟังก์ชัน | การตัด |
|---|---|---|---|
| V0 (all cutting) | A_FUNC_CUTTING_LIST_V0.bas | CUTTING_LIST_V0 | เก็บพฤติกรรมเดิม ตั้ง MixGroups=TRUE เพื่อให้วัสดุเดียวกันจากต่าง PP ใช้เส้นร่วมกันได้ |
| V1 (แยก PP) | A_FUNC_CUTTING_LIST_V1.bas | CUTTING_LIST_V1 | บังคับแยกตามรหัสวัสดุและ PP แต่ละเส้นมีชิ้นงานจาก PP เดียว |

นำเข้าได้พร้อมกันผ่าน Alt+F11 → File → Import File ชื่อโมดูลและชื่อฟังก์ชันต่างกัน แต่ละไฟล์ทำงานได้ด้วยตัวเอง ไม่ต้องนำเข้าไฟล์เดิมเพิ่ม ไฟล์ `A_FUNC_CUTTING_LIST.bas` และสูตร `CUTTING_LIST(...)` เดิมยังคงอยู่

V0 คงค่าเริ่มต้นของ MixGroups เป็น FALSE ตามโค้ดเดิม หากต้องการรวม PP ให้ระบุ TRUE ใน Argument ตัวที่ 7

## Argument ทั้ง 8 ตัว

```excel
=CUTTING_LIST_V0(DataRange,StockLength,Kerf,[TrimStart],[TrimEnd],[MinReusable],[MixGroups],[Direction])
=CUTTING_LIST_V1(DataRange,StockLength,Kerf,[TrimStart],[TrimEnd],[MinReusable],[MixGroups],[Direction])
```

| Argument | ความหมาย | ค่าเริ่มต้น |
|---|---|---|
| DataRange | ตารางสี่เหลี่ยมต่อเนื่อง รวมแถว PP แถวรหัสวัสดุ คอลัมน์ความยาว และช่องจำนวน | ต้องใส่ |
| StockLength | ความยาวเส้นวัตถุดิบ หน่วย มม. | ต้องใส่ |
| Kerf | รอยเลื่อยต่อชิ้น หน่วย มม. | ต้องใส่ |
| TrimStart | ระยะรวมที่เสียจากการตัดแต่งหัวเส้น | 0 |
| TrimEnd | ระยะรวมที่เสียจากการตัดแต่งท้ายเส้น | 0 |
| MinReusable | เศษขั้นต่ำที่เก็บใช้ต่อ หน่วย มม. | 0 |
| MixGroups | V0: TRUE รวม PP / FALSE แยก PP; V1: รับเฉพาะ FALSE หรือเว้นไว้ | FALSE |
| Direction | ทิศทางวางหมวดรายงาน: `"V"` บนลงล่าง / `"H"` ซ้ายไปขวา | `"V"` |

V1 จะคืน `#VALUE!` ถ้าระบุ MixGroups=TRUE เพื่อไม่ให้เงื่อนไขของเวอร์ชันขัดกับสูตรที่เรียกใช้

Argument ตัวที่ 8 เป็นตัวเลือกเพิ่มเติม สูตรเดิมที่ใส่ 7 ตัวหรือน้อยกว่ายังคำนวณแบบบนลงล่างเหมือนเดิม

## ทิศทางจัดรายงาน

`Direction` เปลี่ยนตำแหน่งหมวดรายงานทั้ง 4 หมวด ตารางแต่ละหมวดยังมีหัวคอลัมน์และแถวข้อมูลตามเดิม โดยเฉพาะ Item1…ItemN ยังเป็นหนึ่งชิ้นต่อหนึ่งช่อง ไม่สลับแถวกับคอลัมน์ของข้อมูลต้นทาง

| Direction | การจัดวาง |
|---|---|
| `"V"` | SUMMARY REPORT → ด้านล่างเป็น Target used list → Item used list → CUTTING PLAN |
| `"H"` | SUMMARY REPORT → ด้านขวาเป็น Target used list → Item used list → CUTTING PLAN ทั้งหมดเริ่มแถวเดียวกัน คั่นหมวดละหนึ่งคอลัมน์ว่าง |

ถ้าสูตรเริ่มที่ A1 แบบ H จะวาง SUMMARY REPORT ที่ A1, Target used list ที่ D1, Item used list ที่ Q1 และ CUTTING PLAN ที่ Z1

แบบ V มีความกว้าง `12 + N` คอลัมน์ ส่วนแบบ H มีความกว้าง `37 + N` คอลัมน์ เมื่อ N คือจำนวน Item สูงสุด (อย่างน้อย 1) ความสูงแบบ H เท่าหมวดที่สูงที่สุด ต้องเว้นพื้นที่ Spill ตามทิศทางที่เลือก

รับตัวพิมพ์เล็กและช่องว่างหัวท้าย เช่น `" h "` ได้ แต่ข้อความอื่นหรือ `""` จะคืน `#VALUE!` อ้างอิงเซลล์ที่ใส่ V/H ได้

V1 แบบบนลงล่าง:

```excel
=CUTTING_LIST_V1(AG2:BA27,6000,3,10,10,300,FALSE,"V")
```

V1 แบบซ้ายไปขวา:

```excel
=CUTTING_LIST_V1(AG2:BA27,6000,3,10,10,300,FALSE,"H")
```

V0 รวม PP และวางซ้ายไปขวา:

```excel
=CUTTING_LIST_V0(AG2:BA27,6000,3,10,10,300,TRUE,"H")
```

## สูตรสำหรับตารางแบบในภาพ

V0 — รวม PP ได้เมื่อรหัสวัสดุตรงกัน:

```excel
=CUTTING_LIST_V0(AG2:BA27,6000,3,10,10,300,TRUE)
```

V1 — รายงานรวมเหมือนเดิม แต่ตัดแยก PP:

```excel
=CUTTING_LIST_V1(AG2:BA27,6000,3,10,10,300,FALSE)
```

สูตรสั้นของ V1 (เผื่อหัว–ท้าย 0 มม. และเก็บเศษบวกทั้งหมด):

```excel
=CUTTING_LIST_V1(AG2:BA27,6000,3)
```

ปรับชื่อชีตและขอบเขตให้ตรงไฟล์จริง ถ้าชื่อเรื่องอยู่เหนือหัว PP อย่าเลือกชื่อเรื่องรวมเข้ามา

## อ่าน PP จากตารางอย่างไร

ตัวอย่างช่วง A1:E4:

| แถว | A | B | C | D | E |
|---|---|---|---|---|---|
| 1 | PP | PP17 | (ว่าง) | PP18 | (ว่าง) |
| 2 | Length | M1 | M2 | M1 | M2 |
| 3 | 2200 | 1 | 0 | 1 | 0 |
| 4 | 1600 | 2 | 0 | 2 | 0 |

- คอลัมน์แรกเป็นความยาว แถวก่อนความยาวตัวแรกเป็นรหัสวัสดุ และแถวเหนือรหัสเป็นชื่อ PP
- ช่องว่างในแถว PP สืบทอดชื่อจากด้านซ้าย จึงรองรับหัว PP ที่ Merge แนวนอนตามภาพด้วย
- V1 ต้องมีแถว PP และต้องเลือกครอบคลุมเซลล์ซ้ายสุดที่มีชื่อ PP ห้ามเลือกเฉพาะหัวรหัสวัสดุ เพราะจะไม่ทราบว่าชิ้นงานมาจาก PP ใด
- ชื่อ P17, PP17 หรือชื่ออื่นใช้ได้ตามข้อความจริงในเซลล์ ไม่มีการล็อกเลข PP ในโค้ด ชื่อซ้ำถือเป็น PP เดียวกัน โดยไม่แยกตัวพิมพ์เล็ก–ใหญ่และตัดช่องว่างหัวท้าย
- วัสดุรหัสเดียวกันของ PP17 กับ PP18 จะถูกจัดลงคนละชุดเส้นใน V1 ทั้งจำนวนชิ้นและความยาวยังสรุปรวมในรายงานเดียว

## ทวนสอบผลลัพธ์

หมวด 4 ยังแสดง Material / Group (PP) / Bar / Stock / Item1…ItemN / Group cuts / Pieces และท้ายแถว 6 ช่องตามเดิม V1 จะไม่มีเส้นที่ผสม PP ส่วนจำนวนเส้นเริ่มใหม่ตามแต่ละชุดวัสดุและ PP

ตรวจจำนวนได้จาก Item used list และตรวจแต่ละเส้นได้จาก:

```text
SUM(Item1…ItemN) + Kerf loss + Trim loss + Remainder = Stock
```

จำนวนเส้นของ V1 อาจมากกว่า V0 ที่เปิดรวม PP เพราะใช้เศษพื้นที่ว่างข้าม PP ร่วมกันไม่ได้ วิธีจัดแผนยังเป็นการประมาณคำตอบ ไม่รับรองจำนวนเส้นต่ำสุดทุกกรณี ขีดจำกัดและวิธีนับรอยเลื่อยเหมือนคู่มือ CUTTING_LIST เดิม
