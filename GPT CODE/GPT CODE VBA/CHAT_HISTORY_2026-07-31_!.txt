1. งานตรวจแบบ PERFORMANCE LOUVER
======================================================================

หลักเกณฑ์ที่ตกลงร่วมกัน:

1) เปรียบเทียบ Heading ใต้รูปกับ Drawing Title ใน Title Block
2) ข้อความตั้งแต่คำว่า PERFORMANCE LOUVER เป็นต้นไปต้องตรงกัน
3) ไม่พิจารณาความแตกต่างของตัวพิมพ์เล็ก–ใหญ่และช่องว่าง
4) ต้องตรวจหมายเลขกำกับรูปในวงกลม/บับเบิลให้ตรงกับชื่อรูป
5) ต้องตรวจ Drawing No. ภายในแบบให้ตรงกับชื่อไฟล์ PDF
6) ต้อง Render PDF และตรวจภาพจริง ไม่ใช้ Text Extraction เพียงอย่างเดียว

เกณฑ์ Scale:

- Plan = 1:100
- Elevation = 1:100
- Section = โดยทั่วไป 1:40, 1:50 หรือ 1:60
- Detail = 1:10
- ถ้า Section ใช้ Scale ผิดแปลกจากชุดหลัก ต้องแจ้งผู้ใช้

กรณีไม่มี Heading:

- Plan: ภาพมองจากด้านบน เห็นผัง Grid แนวผนังและขอบอาคาร
- Elevation: รูปด้าน เห็นความสูงและระดับ FFL
- Section: ภาพตัด เห็นชั้นวัสดุและโครงสร้างตามแนวดิ่ง
- Detail: ภาพขยายเฉพาะจุด เห็น Bracket สกรู รอยต่อ และมิติย่อย
- ถ้ารูปไม่ชัดเจน ต้องแจ้งว่าไม่สามารถยืนยันได้ ไม่ควรเดา

7. ข้อควรระวังสำหรับงานครั้งถัดไป
======================================================================

- ตรวจรายชื่อ PDF ใหม่ทุกครั้ง เพราะเลขไฟล์อาจมีการแก้ไข
- อย่าใช้รายชื่อจากรอบก่อนโดยไม่ตรวจโฟลเดอร์ปัจจุบัน
- ถ้ามี DWG ชื่อตรงกันอยู่แล้ว ห้ามเขียนทับโดยไม่ตรวจหรือไม่ได้รับคำสั่ง
- หลังคัดลอกต้องเปรียบเทียบชื่อฐาน PDF กับ DWG
- ไฟล์ DWG ต้นฉบับไม่ต้องมีชื่อคู่กับ PDF และควรเก็บไว้ใน CAD
- จำนวน DWG ใน CAD จะเท่ากับจำนวน PDF + 1 เมื่อรวม DWG ต้นฉบับ
