สรุปงานตรวจแบบ PERFORMANCE LOUVER
วันที่สรุป: 24 กรกฎาคม 2026

======================================================================
1. วัตถุประสงค์
======================================================================

ตรวจสอบข้อมูลในแบบ PDF ของ PERFORMANCE LOUVER โดยเปรียบเทียบ:

1) Heading ใต้รูปแบบ
2) Drawing Title ใน Title Block
3) หมายเลขกำกับรูปในวงกลม/บับเบิล
4) Scale ของ Plan, Elevation, Section และ Detail
5) Drawing No. ภายในแบบกับชื่อไฟล์ PDF


======================================================================
2. คำศัพท์ที่ใช้
======================================================================

Heading
- ชื่อขนาดใหญ่ที่อยู่ใต้รูป เช่น:
  ENTRANCE 2 - PERFORMANCE LOUVER LOWER ROOF PLAN

Drawing Title
- ชื่อแบบขนาดเล็กภายใน Title Block ด้านล่างขวา เช่น:
  ENTRANCE 2 - PERFORMANCE LOUVER
  LOWER ROOF PLAN

ข้อความที่ต้องเปรียบเทียบ
- ข้อความตั้งแต่คำว่า PERFORMANCE LOUVER เป็นต้นไปใน Heading
- ต้องตรงกับ Drawing Title
- ไม่นับความแตกต่างของตัวพิมพ์เล็ก–ใหญ่
- ไม่นับช่องว่าง
- คำ ตัวเลข เครื่องหมาย และลำดับข้อมูลยังต้องตรงกัน


======================================================================
3. เกณฑ์ Scale
======================================================================

PLAN
- Scale มาตรฐาน: 1:100

ELEVATION
- Scale มาตรฐาน: 1:100

SECTION
- Scale ที่พบเป็นหลัก: 1:40, 1:50 หรือ 1:60
- ถ้าพบ Scale อื่น ต้องแจ้งให้ผู้ใช้ตรวจสอบ แม้ Heading และ Drawing Title จะตรงกัน

DETAIL
- Scale มาตรฐาน: 1:10

หมายเหตุ
- ต้องตรวจ Scale ใต้ Heading ของแต่ละรูป ไม่อาศัยเฉพาะ Scale รวมใน Title Block
- Scale ใน Title Block เช่น A1 และ A3 อาจต่างกันตามขนาดกระดาษ จึงไม่ใช้แทน Scale ใต้รูป


======================================================================
4. การจำแนกประเภทรูปเมื่อไม่มี Heading
======================================================================

PLAN
- มองจากด้านบน
- เห็นแนวผัง Grid ขอบอาคาร แนวผนัง และตำแหน่งองค์ประกอบ

ELEVATION
- มองด้านหน้า/ด้านข้าง
- เห็นรูปด้าน ความสูง และระดับ FFL

SECTION
- เป็นภาพตัด
- เห็นชั้นวัสดุ โครงสร้าง และระดับตามแนวดิ่ง
- มักมี Section Mark เช่น A-1 หรือ B-1

DETAIL
- เป็นภาพขยายเฉพาะจุด
- มีมิติย่อย วัสดุ สกรู Bracket รอยต่อ หรือชิ้นส่วนประกอบ
- ปกติใช้ Scale 1:10

ถ้ารูปไม่มี Heading และลักษณะยังไม่ชัดเจน:
- ห้ามเดาโดยไม่แจ้ง
- ให้ระบุว่า “ไม่พบ Heading/ไม่สามารถยืนยันประเภทรูปได้”


======================================================================
5. ขั้นตอนตรวจต่อหนึ่งไฟล์
======================================================================

1) ตรวจชื่อไฟล์ PDF
2) ตรวจ Drawing No. ใน Title Block ว่าตรงกับชื่อไฟล์
3) อ่าน Drawing Title
4) อ่าน Heading ของทุกรูปในแผ่น
5) เปรียบเทียบ Heading กับ Drawing Title ตามกฎข้อ 2
6) ตรวจวงกลมหรือบับเบิลกำกับรูป เช่น:
   - ELEVATION 2 ต้องเป็นวงกลม 2
   - ELEVATION 4 ต้องเป็นวงกลม 4
   - SECTION A-1 ต้องเป็นวงกลม A-1
   - DETAIL 11 ต้องเป็นวงกลม 11
7) ตรวจ Scale ใต้ Heading ทุกรูป
8) Render PDF เป็นภาพและตรวจด้วยสายตาอีกครั้ง
9) สรุปแยกเป็น “ผ่าน” และ “ต้องแก้”


======================================================================
6. รูปแบบการแจ้งข้อผิดพลาด
======================================================================

ให้แจ้งอย่างน้อย:

- ชื่อไฟล์
- Heading ที่พบ
- Drawing Title ที่พบ
- จุดที่ไม่ตรง
- Scale ที่พบและ Scale ที่ควรเป็น
- หมายเลขวงกลมที่พบและหมายเลขที่ควรเป็น
- Drawing No. ภายใน หากไม่ตรงกับชื่อไฟล์

ตัวอย่าง:

ไฟล์: W-1-XXXX-AR-XXXX-XX-A.pdf
สถานะ: ต้องแก้
- Heading: PERFORMANCE LOUVER SECTION A-1
- Drawing Title: SECTION B-1
- วงกลมกำกับรูป: B-1
- Scale: 1:100
- ควรตรวจแก้ชื่อ Section ให้ตรงกัน และ Scale ควรอยู่ในกลุ่ม
  1:40 / 1:50 / 1:60

9. แนวทางสำหรับพัฒนา VBA/ระบบตรวจอัตโนมัติ
======================================================================

การ Normalize ข้อความก่อนเปรียบเทียบ:

1) แปลงเป็นตัวพิมพ์ใหญ่ทั้งหมด
2) ลบช่องว่าง Tab และการขึ้นบรรทัดใหม่
3) คงตัวเลขและเครื่องหมายไว้
4) ตัดข้อความก่อนคำว่า PERFORMANCE LOUVER ออกจาก Heading หากต้องการ
   เปรียบเทียบเฉพาะชื่อแบบส่วนท้าย

ตัวอย่าง:

Heading:
ENTRANCE 2 - PERFORMANCE LOUVER LOWER ROOF PLAN

Drawing Title:
ENTRANCE 2 - PERFORMANCE LOUVER
LOWER ROOF PLAN

ค่าหลัง Normalize:
ENTRANCE2-PERFORMANCELOUVERLOWERROOFPLAN

ข้อควรระวังสำหรับระบบอัตโนมัติ:

- PDF บางไฟล์แยกข้อความออกเป็นหลายบรรทัดหรือหลาย Text Object
- วงกลมกำกับรูปอาจถูกแยกจากข้อความ Heading
- OCR อาจอ่าน 1, I, 0, O, เครื่องหมายขีด และจุดผิด
- ต้องมีการ Render และตรวจด้วยสายตาสำหรับไฟล์ที่ระบบระบุว่าไม่แน่ใจ
- ไม่ควรตัดสิน Scale จากเลขใน Title Block เพียงอย่างเดียว
- Section ที่ใช้ Scale นอก 1:40, 1:50, 1:60 ให้ขึ้น Warning
