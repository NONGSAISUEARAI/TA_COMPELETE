# คู่มือ COUNTUNIQUE_V6 และ SUMUNIQUE_V6

ไฟล์นี้อธิบายลำดับอาร์กิวเมนต์ ตัวอย่างที่คัดลอกได้ และการแก้ `#VALUE!` โดยฟังก์ชันยังคืนข้อผิดพลาด Excel ตามเดิม

## 1. ลำดับอาร์กิวเมนต์

COUNT ใช้นับจำนวนแถวที่ตรงกับชุดเงื่อนไข:

```excel
=COUNTUNIQUE_V6(Heading,IncludeEmpty,Range1,Sort1,Range2,Sort2,...)
```

SUM ใช้บวกยอดของแถวที่ตรงกับชุดเงื่อนไข:

```excel
=SUMUNIQUE_V6(Heading,IncludeEmpty,SumRange,Range1,Sort1,Range2,Sort2,...)
```

บรรทัดข้างบนเป็นรูปแบบอธิบาย ให้แทนชื่ออาร์กิวเมนต์ด้วยค่าจริง ตัวอย่างพร้อมใช้ในหัวข้อถัดไป

| อาร์กิวเมนต์ | วิธีใส่ |
|---|---|
| `Heading` | ชื่อหัวข้อในเครื่องหมายคำพูด เช่น `"SS"` หรืออ้างอิงเซลล์เดียว เช่น `K1`; ใช้ `""` เมื่อต้องการตัดแถวชื่อเรื่องออก แต่ยังต้องใส่อาร์กิวเมนต์นี้ |
| `IncludeEmpty` | `1` แสดงทุกการจับคู่ของหัวแนวนอน; `0` แสดงเฉพาะชุดหัวแนวนอนที่พบในข้อมูลที่นำมาคำนวณ |
| `SumRange` | เฉพาะ SUM: ช่วงตัวเลขที่จะบวก อยู่ตำแหน่งที่ 3 เช่น `M3:M101` และไม่ต้องใส่ Sort ตามหลังช่วงนี้ |
| `Range1` | ช่วงรายการที่จะแสดงแนวตั้งด้านซ้าย |
| `Sort1` | การเรียงรายการแนวตั้ง: `1` น้อยไปมาก; `0` ตามลำดับที่พบ |
| `Range2, Sort2` | ช่วงหัวแนวนอนชั้นแรก และค่าการเรียงของชั้นนั้น |
| `Range3, Sort3` | ช่วงหัวแนวนอนชั้นที่สอง และค่าการเรียงของชั้นนั้น |
| คู่ถัดไป | เพิ่ม `Range4,Sort4` และคู่ถัดไปต่อท้ายได้ ภายในขีดจำกัดอาร์กิวเมนต์และขนาดชีตของ Excel |

ต้องมีอย่างน้อย **2 คู่ช่วงข้อมูลกับ Sort**: COUNT มีอย่างน้อย 6 อาร์กิวเมนต์; SUM มีอย่างน้อย 7 อาร์กิวเมนต์

`IncludeEmpty=1` หมายถึงแสดง **ชุดหัวตารางที่ไม่มีข้อมูลตรงกัน** ไม่ได้หมายถึงนำเซลล์ว่างในต้นทางมาเป็นหมวด เซลล์ว่าง ช่องที่มีแต่เว้นวรรค และ Error ในช่วงเงื่อนไขจะทำให้ข้ามข้อมูลแถวนั้น

การเรียง `0` ใช้ลำดับค่าที่พบของแต่ละช่วง แล้วจัดกลุ่มตามชั้นหัวตาราง ส่วน `1` เรียงตัวเลขน้อยไปมาก หรือเรียงข้อความแบบไม่แยกตัวพิมพ์ใหญ่เล็ก

## 2. ตัวอย่างพร้อมใช้กับช่วงข้อมูลของคุณ

สมมติ L เป็นรายการแนวตั้ง, F เป็นหมวดแนวนอน, G เป็นหัวย่อย และ M เป็นยอดที่จะรวม เลือกแถว 3–101 โดยไม่รวมหัวคอลัมน์

นับแบบ 2 ช่วงเงื่อนไข:

```excel
=COUNTUNIQUE_V6("SS",1,L3:L101,1,F3:F101,0)
```

นับแบบ 3 ช่วงเงื่อนไข เพิ่มหัวย่อยจาก G:

```excel
=COUNTUNIQUE_V6("SS",1,L3:L101,1,F3:F101,1,G3:G101,0)
```

รวมยอดจาก M โดยใช้ 2 ช่วงเงื่อนไข:

```excel
=SUMUNIQUE_V6("SS",1,M3:M101,L3:L101,1,F3:F101,0)
```

รวมยอดจาก M โดยใช้ 3 ช่วงเงื่อนไข:

```excel
=SUMUNIQUE_V6("SS",1,M3:M101,L3:L101,1,F3:F101,1,G3:G101,0)
```

เพิ่มหัวแนวนอนอีกหนึ่งชั้นจาก H:

```excel
=COUNTUNIQUE_V6("SS",1,L3:L101,1,F3:F101,1,G3:G101,0,H3:H101,1)
=SUMUNIQUE_V6("SS",1,M3:M101,L3:L101,1,F3:F101,1,G3:G101,0,H3:H101,1)
```

แสดงเฉพาะชุดที่พบ และไม่ใส่ชื่อเรื่อง:

```excel
=COUNTUNIQUE_V6("",0,L3:L101,1,F3:F101,0,G3:G101,0)
=SUMUNIQUE_V6("",0,M3:M101,L3:L101,1,F3:F101,0,G3:G101,0)
```

หากชื่อเรื่องอยู่ใน K1 ให้ใช้ `K1` แทน `"SS"` ในตำแหน่งแรกของสูตรได้

## 3. ตัวอย่างข้อมูลและผลลัพธ์

ตัวอย่างเล็กนี้ใช้ช่วง A2:D5:

| แถว | A: รายการแนวตั้ง | B: หมวด | C: หัวย่อย | D: ยอด |
|---|---|---|---|---|
| 2 | P01 | A | qq | 10 |
| 3 | P01 | A | qq | 15 |
| 4 | P01 | B | erw | 7 |
| 5 | P02 | B | erw | -2 |

```excel
=COUNTUNIQUE_V6("นับ",1,A2:A5,0,B2:B5,0,C2:C5,0)
=SUMUNIQUE_V6("รวม",1,D2:D5,A2:A5,0,B2:B5,0,C2:C5,0)
```

ทั้งสองสูตรมีคอลัมน์ข้อมูลเรียงเป็น `A → qq`, `A → erw`, `B → qq`, `B → erw` หัวหมวดชั้นบนแสดงที่ต้นกลุ่ม แต่ละหมวดมีหัวย่อยครบชุด

ตารางด้านล่างรวมชื่อหัวทั้งสองชั้นไว้เพื่อให้อ่านง่าย ช่องที่ไม่มีข้อมูลแสดงว่าง:

| รายการ | COUNT: A/qq | SUM: A/qq | COUNT: B/erw | SUM: B/erw |
|---|---|---|---|---|
| P01 | 2 | 25 | 1 | 7 |
| P02 |  |  | 1 | -2 |

เมื่อเปลี่ยนอาร์กิวเมนต์ที่ 2 เป็น `0` จะเหลือเฉพาะคอลัมน์ `A → qq` และ `B → erw` ตัวเลขที่นับหรือรวมในคอลัมน์เหล่านี้เหมือนเดิม

SUM ข้ามยอดว่าง, Error, ข้อความที่ไม่ใช่ตัวเลข และ TRUE/FALSE แต่รับข้อความที่เป็นตัวเลข ยอดศูนย์ และยอดติดลบ ผลรวมที่หักล้างเป็นศูนย์ยังแสดง `0`; ช่องที่ไม่มีแถวข้อมูลที่ใช้รวมได้แสดงว่าง

## 4. #VALUE! เกิดจากอะไร และแก้อย่างไร

### ต้องจับคู่ช่วงกับ Sort ให้ครบ

สูตรผิด — ลืม Sort ของช่วง F:

```excel
=COUNTUNIQUE_V6("SS",1,L3:L101,1,F3:F101)
```

สูตรถูก:

```excel
=COUNTUNIQUE_V6("SS",1,L3:L101,1,F3:F101,1)
```

### SUM ต้องใส่ช่วงยอดรวมเป็นตัวที่ 3

สูตรผิด — ใช้รูปแบบ COUNT แล้วเปลี่ยนชื่อเป็น SUM โดยไม่ได้เพิ่มช่วงยอดรวม:

```excel
=SUMUNIQUE_V6("SS",1,L3:L101,1,F3:F101,1)
```

สูตรถูก — เพิ่ม M เป็นช่วงยอดรวม:

```excel
=SUMUNIQUE_V6("SS",1,M3:M101,L3:L101,1,F3:F101,1)
```

### ตรวจค่าที่เหลือในตารางนี้

| สาเหตุหลักของ #VALUE! | ตัวอย่างที่ผิด | วิธีแก้ |
|---|---|---|
| IncludeEmpty ไม่ใช่ 0 หรือ 1 | อาร์กิวเมนต์ที่ 2 เป็น `2` | ใช้ `0` หรือ `1` |
| Sort ไม่ใช่ 0 หรือ 1 | Sort เป็น `2`, `-1`, `0.5` หรือ `"asc"` | ใช้ `0` หรือ `1` |
| ช่วงถูกใส่เป็นข้อความ | `"L3:L101"` | ใช้ `L3:L101` โดยไม่ครอบเครื่องหมายคำพูด |
| มีเพียงช่วงแนวตั้งชุดเดียว | มีแค่ `L3:L101,1` | เพิ่มช่วงหัวแนวนอนและ Sort อย่างน้อยอีกหนึ่งคู่ |
| ใช้ลำดับอาร์กิวเมนต์รุ่นเก่า | ใส่ Heading ท้ายสูตร หรือใส่ SumRange ท้ายสูตร | เรียงตามรูปแบบ V6 ด้านบน |
| Heading อ้างอิงหลายเซลล์ | Heading เป็น `K1:K2` | ใช้เซลล์เดียว เช่น `K1` หรือข้อความ เช่น `"SS"` |
| เซลล์อ้างอิงของ flag ไม่ถูกต้อง | IncludeEmpty/Sort อ้างอิงช่องว่าง, Error หรือหลายเซลล์ | ใช้เซลล์เดียวที่มีค่า 0 หรือ 1 |

ไม่ต้องซ่อนข้อผิดพลาดด้วย IFERROR ระหว่างตรวจสูตร เพราะจะทำให้มองไม่เห็นสาเหตุ ค่อยใช้หลังตรวจอาร์กิวเมนต์ครบแล้วตามต้องการ

## 5. แยก #VALUE! ออกจากข้อผิดพลาดอื่น

| ข้อผิดพลาด | ความหมายและวิธีตรวจ |
|---|---|
| `#REF!` | ช่วงมีจำนวนเซลล์ไม่เท่ากัน หรือเป็นช่วงหลายพื้นที่ที่ไม่ต่อกัน เช่น L3:L101 มี 99 เซลล์ แต่ F3:F100 มี 98 เซลล์ |
| `#NUM!` | ผลลัพธ์ใหญ่เกินขนาดชีต/ทรัพยากร หรือยอดรวมล้นขนาดตัวเลข ลองลดระดับหรือจำนวนค่าของหัวตาราง หรือใช้ IncludeEmpty=0 เพื่อลดคอลัมน์ |
| `#SPILL!` | ตรวจพื้นที่ด้านขวาและด้านล่างของสูตร รวมถึงเซลล์ผสานที่ขวางผลลัพธ์ |
| `#NAME?` | ตรวจชื่อฟังก์ชัน การนำเข้าโมดูล .bas และการอนุญาตใช้แมโครในสมุดงาน |

ทุกช่วงควรเริ่มและจบแถวเดียวกัน และควรเลือกข้อมูลโดยไม่รวมหัวคอลัมน์ ช่วงที่มีจำนวนเซลล์ต่างกันคืน `#REF!` ส่วนเซลล์ว่างหรือ Error ภายในข้อมูลต้นทางจะถูกข้ามตามกติกาข้างต้น
