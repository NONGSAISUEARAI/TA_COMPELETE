1. ทบทวนวิธีใช้ copyallsheet_v3
======================================================================

ไฟล์ Module:
A_FUNC_copyallsheet_v3.bas

ตำแหน่ง:
C:\Users\tawan.t\Documents\GitHub\TA_COMPELETE\GPT CODE\GPT CODE VBA\A_FUNC_copyallsheet_v3.bas

รูปแบบสูตร:
=copyallsheet_v3(SourceRange,StartSheet,CopySheetCount,[FilterEmptyRows])

ความหมาย Argument:
1. SourceRange
   ช่วงหรือตำแหน่งข้อมูลที่ต้องการดึงจากแต่ละ Sheet

2. StartSheet
   จุดเริ่มต้นของ Sheet รับได้ทั้งชื่อ Sheet และหมายเลขลำดับ Sheet

3. CopySheetCount
   จำนวน Sheet ที่ต้องการดึงต่อเนื่องจากจุดเริ่มต้น

4. FilterEmptyRows
   Argument ไม่บังคับ
   - 1 = ตัดแถวที่ทุกเซลล์ใน SourceRange ว่างทั้งหมด
   - 0 = เก็บแถวว่างไว้
   - ไม่ใส่ = ใช้ค่าเริ่มต้น 0

ตัวอย่างเริ่มจากชื่อ Sheet และกรองแถวว่าง:
=copyallsheet_v3(A1:D100,"PP17",5,1)

ตัวอย่างเริ่มจากลำดับ Sheet:
=copyallsheet_v3(A1:D100,3,5,1)

ตัวอย่างไม่กรองแถวว่าง:
=copyallsheet_v3(A1:D100,"PP17",5,0)

หรือ:
=copyallsheet_v3(A1:D100,"PP17",5)

ลักษณะผลลัพธ์:
- ผลลัพธ์เป็น Dynamic Array แบบ Spill
- คอลัมน์แรกแสดงชื่อ Sheet
- คอลัมน์ถัดไปแสดงข้อมูลจาก SourceRange
- ต้องเว้นพื้นที่ปลายทางให้ว่าง มิฉะนั้น Excel จะแสดง #SPILL!

2. สูตร IFS สำหรับสลับค่า K3 และ T3 ตาม Z3
======================================================================

เงื่อนไขที่ผู้ใช้ต้องการ:
- ถ้า Z3 ไม่มีข้อมูล ให้คืนค่าว่าง
- ถ้า Z3 = "START L" ให้ผลแรกเป็น K3 และผลที่สองเป็น T3
- ถ้า Z3 เป็นค่าอื่น ให้ผลแรกเป็น T3 และผลที่สองเป็น K3

สูตรแยกช่องแรก:
=IFS($Z3="","",$Z3="START L",$K3,TRUE,$T3)

สูตรแยกช่องที่สอง:
=IFS($Z3="","",$Z3="START L",$T3,TRUE,$K3)

======================================================================
3. รวมสูตร IFS เป็นสูตรเดียวและ Spill สองคอลัมน์
======================================================================

สูตรรวม:
=IFS($Z3="",CHOOSE({1,2},"",""),$Z3="START L",CHOOSE({1,2},$K3,$T3),TRUE,CHOOSE({1,2},$T3,$K3))

การทำงาน:
- Z3 ว่าง:
  คืนค่าว่างสองคอลัมน์

- Z3 = "START L":
  คอลัมน์แรก = K3
  คอลัมน์ที่สอง = T3

- Z3 เป็นค่าอื่น:
  คอลัมน์แรก = T3
  คอลัมน์ที่สอง = K3

ข้อควรระวัง:
- ใส่สูตรในเซลล์แรกเพียงเซลล์เดียว
- เซลล์ด้านขวาต้องว่าง เพื่อให้ผลลัพธ์ Spill ได้
- สูตรนี้เหมาะกับ Excel 2021 ที่รองรับ Dynamic Arrays
- หาก Excel ใช้ semicolon เป็นตัวคั่น Argument อาจต้องเปลี่ยน comma เป็น semicolon
