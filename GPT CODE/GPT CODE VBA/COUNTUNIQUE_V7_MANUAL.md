# COUNTUNIQUE_V7 — คู่มือสรุป

ไฟล์โค้ด: [A_FUNC_CountUnique_V7.bas](A_FUNC_CountUnique_V7.bas) รุ่น V7 แยกจาก V6 และเพิ่มการเรียงจากมากไปน้อยในแต่ละช่วงข้อมูล

```excel
=COUNTUNIQUE_V7(Heading,IncludeEmpty,Range1,Sort1,Range2,Sort2,...)
```

| ตำแหน่ง | Argument | ความหมาย |
| --- | --- | --- |
| 1 | `Heading` | หัวเรื่อง เช่น `"SUMMARY"`; ใช้ `""` เพื่อไม่แสดง |
| 2 | `IncludeEmpty` | `0` แสดงเฉพาะชุดหัวคอลัมน์ที่พบจริง; `1` แสดงทุกชุดที่เป็นไปได้ |
| 3–4 | `Range1,Sort1` | ค่าแถวแนวตั้งและวิธีเรียง |
| 5–6 | `Range2,Sort2` | หัวคอลัมน์แนวนอนระดับแรกและวิธีเรียง |
| ต่อไป | `Range3,Sort3,...` | เพิ่มระดับหัวคอลัมน์ โดยใส่ช่วงและวิธีเรียงเป็นคู่ |

`Sort` ใช้แยกกันสำหรับแต่ละ `Range`:

| ค่า | ผล |
| --- | --- |
| `0` | ไม่เรียง ใช้ลำดับที่พบในข้อมูล |
| `1` หรือ `"1<"` | เรียงจากน้อยไปมาก |
| `"1>"` | เรียงจากมากไปน้อย |

`"1<"` และ `"1>"` ต้องใส่เครื่องหมายคำพูดในสูตร เพราะเป็นข้อความ ไม่ใช่ตัวเลข

ตัวอย่างตามข้อมูลของคุณ: เรียง `V` จากมากไปน้อย และ `Q` จากน้อยไปมาก

```excel
=COUNTUNIQUE_V7("SUMMARY",0,V3:V470,"1>",Q3:Q470,"1<")
```

ถ้าต้องการคงลำดับที่พบของ `V` แต่เรียง `Q` จากมากไปน้อย:

```excel
=COUNTUNIQUE_V7("SUMMARY",0,V3:V470,0,Q3:Q470,"1>")
```

**เงื่อนไขข้อมูล:** ต้องมีอย่างน้อย 2 คู่ `Range,Sort`; ทุกช่วงต้องมีจำนวนเซลล์เท่ากัน แถวที่ key ว่างหรือมี error จะถูกข้าม ค่า `0` เป็นข้อมูลที่ใช้ได้ ช่องที่ไม่มีจำนวนแสดงว่าง ผลลัพธ์เป็น dynamic array จึงต้องมีพื้นที่ว่างให้ spill

**ความเข้ากันได้:** `1` ยังหมายถึงเรียงจากน้อยไปมากตาม V6 ส่วน V6 เดิมไม่ได้ถูกแก้ไข
