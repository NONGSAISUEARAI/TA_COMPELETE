5. SUMUNIQUE
======================================================================

ไฟล์: SumUnique.bas
ฟังก์ชัน: SUMUNIQUE

วัตถุประสงค์:
- คืน Dynamic Array แบบ Spill สองคอลัมน์
- คอลัมน์ 1 = Unique List
- คอลัมน์ 2 = Total Value
- ใช้ Application.SumIfs เพื่อรวมยอดของแต่ละรายการ
- ข้ามเซลล์ว่างและ Error ในช่วงรายการ

รูปแบบสูตร:
=SUMUNIQUE(A1:A20)

ถ้าแยกคอลัมน์รายการและยอด:
=SUMUNIQUE(A1:A20,B1:B20)

ข้อกำหนด:
- UniqueRange และ SumRange ต้องมีจำนวนเซลล์เท่ากัน
- ถ้าไม่ใส่ SumRange จะใช้ UniqueRange เป็น SumRange

6. COUNTUNIQUE เวอร์ชันแรก
======================================================================

ไฟล์: CountUnique.bas
ฟังก์ชัน: COUNTUNIQUE

สำคัญ:
- ผู้ใช้สั่งให้คงเวอร์ชันแรกเหมือนตอนสร้างไฟล์

Unique List | Count

- นับจำนวนครั้งที่พบแต่ละรายการ
- ไม่สนใจเซลล์ว่างและ Error
- เปรียบเทียบข้อความแบบไม่สนตัวพิมพ์เล็ก/ใหญ่

7. COUNTUNIQUE_V2
======================================================================

ไฟล์: CountUnique_V2.bas
ฟังก์ชัน: COUNTUNIQUE_V2

แนวคิดตาราง:
- เงื่อนไขที่ 1 = รายการแนวตั้งด้านซ้าย
- เงื่อนไขที่ 2 = หัวกลุ่มแนวนอนด้านบน
- เงื่อนไขที่ 3 = ซับย่อยใต้เงื่อนไขที่ 2
- ช่องตัดกัน = จำนวนครั้งที่ตรงครบทุกเงื่อนไข
- ถ้าไม่พบข้อมูล คืนค่า "" แทน 0
- เงื่อนไขที่ 3 เป็น Optional
- Heading เป็น Optional และเป็น Argument ท้ายสุด

สูตรแบบสองเงื่อนไข:
=COUNTUNIQUE_V2(Condition1Range,Condition2Range)

ตัวอย่าง:
=COUNTUNIQUE_V2(U3:U345,P3:P345)

สูตรแบบสามเงื่อนไข:
=COUNTUNIQUE_V2(Condition1Range,Condition2Range,Condition3Range)

สูตรสามเงื่อนไขพร้อม Heading:
=COUNTUNIQUE_V2(A2:A100,B2:B100,C2:C100,"CUTTING PLAN")

สูตรไม่มีเงื่อนไขที่ 3 แต่มี Heading:
=COUNTUNIQUE_V2(A2:A100,B2:B100,,"CUTTING PLAN")

รองรับรูปแบบย่อ โดยส่ง Heading เป็น Argument ที่ 3 ซึ่งไม่ใช่ Range:
=COUNTUNIQUE_V2(A2:A100,B2:B100,"CUTTING PLAN")

ข้อควรจำ:
- Formula Spill ไม่สามารถ Merge เซลล์ Heading หรือหัวกลุ่มอัตโนมัติ
- Heading จึงอยู่ที่เซลล์แรกของบรรทัดแรก ส่วนช่องที่เหลือคืน ""
- ทุกช่วงเงื่อนไขต้องมีจำนวนเซลล์เท่ากัน
- V2 ไม่รับผลลัพธ์ SORT(...) ใน Argument ที่ประกาศเป็น Range
- ห้าม SORT เฉพาะเงื่อนไขหนึ่งก่อนส่งเข้า UDF เพราะจะทำให้ข้อมูลแต่ละแถว
  ไม่ตรงคู่กับเงื่อนไขอื่น

8. COUNTUNIQUE_V3
======================================================================

ไฟล์: CountUnique_V3.bas
ฟังก์ชัน: COUNTUNIQUE_V3

เหตุผลที่สร้าง V3:
- ผู้ใช้เคยลองสูตร:
  =COUNTUNIQUE_V2(SORT(U3:U345,1,1),P3:P345)
- การ SORT เฉพาะคอลัมน์ U ทำให้ข้อมูลไม่ตรงกับคอลัมน์ P
- จึงเพิ่มระบบ Sort ภายในฟังก์ชันหลังจากนับข้อมูลเสร็จ
- V2 ต้องคงอยู่ ไม่ถูกแทนที่

ลำดับ Argument:
=COUNTUNIQUE_V3(Condition1Range,SortFlag,Condition2Range,[Condition3Range],[Heading])

SortFlag:
- 1 = เรียง Unique ของเงื่อนไขที่ 1 จากน้อยไปมาก
- 0 = ไม่เรียง และคงลำดับที่พบในข้อมูลต้นทาง
- ค่าอื่นคืน #VALUE!

ตัวอย่างแทนการใช้ SORT:
=COUNTUNIQUE_V3(U3:U345,1,P3:P345)

ไม่เรียง:
=COUNTUNIQUE_V3(U3:U345,0,P3:P345)

มีเงื่อนไขที่ 3 และ Heading:
=COUNTUNIQUE_V3(U3:U345,1,P3:P345,Q3:Q345,"CUTTING PLAN")

ไม่มีเงื่อนไขที่ 3 แต่มี Heading:
=COUNTUNIQUE_V3(U3:U345,1,P3:P345,,"CUTTING PLAN")

พฤติกรรม Sort:
- ถ้าทั้งสองค่าเป็นตัวเลข จะเรียงแบบตัวเลข
- ถ้าไม่ใช่ตัวเลข จะเรียงข้อความแบบไม่สนตัวพิมพ์เล็ก/ใหญ่
- เรียงเฉพาะ Unique Row Labels หลังนับแล้ว จึงไม่ทำลายความสัมพันธ์ของข้อมูล

9. UNIQUEIFS
======================================================================

ไฟล์: UniqueIfs.bas
ฟังก์ชัน: UNIQUEIFS

วัตถุประสงค์:
- เลือก Unique List ตามเงื่อนไขหนึ่งข้อหรือหลายข้อ
- คืน Dynamic Array แนวตั้งหนึ่งคอลัมน์
- รับเงื่อนไขเป็นคู่ CriteriaRange, Criteria คล้าย SUMIFS/COUNTIFS

Syntax:
=UNIQUEIFS(UniqueRange,CriteriaRange1,Criteria1,[CriteriaRange2,Criteria2],...)

ตัวอย่างหนึ่งเงื่อนไข:
=UNIQUEIFS(A2:A100,B2:B100,"PP17")

ตัวอย่างสองเงื่อนไข:
=UNIQUEIFS(A2:A100,B2:B100,"PP17",C2:C100,"STD-LENGTH_1500")

อ้างอิงเงื่อนไขจากเซลล์:
=UNIQUEIFS(A2:A100,B2:B100,E1,C2:C100,D2)

ตัวอย่าง Operator:
=UNIQUEIFS(A2:A100,D2:D100,">1700")

ข้อกำหนด:
- ต้องมีเงื่อนไขอย่างน้อยหนึ่งคู่
- จำนวน Argument เงื่อนไขต้องเป็นเลขคู่
- ทุก CriteriaRange ต้องมีจำนวนเซลล์เท่ากับ UniqueRange
- ข้ามรายการ Unique ที่เป็นช่องว่างหรือ Error
- ใช้ Application.CountIf สำหรับตรวจเงื่อนไข จึงรองรับ Operator และ Wildcard

11. CONDITIONAL FORMATTING: BLANK / NON-BLANK
======================================================================

ไฟล์: Format_Blank_NonBlank.bas
Macro หลัก: ApplyBlankNonBlankFormatting

ผู้ใช้ส่งภาพ Rules Manager ซึ่งมีกฎสองรายการ:
- Cell does not contain a blank value
- Cell contains a blank value
- Applies to ทั้ง Worksheet ประมาณ =$1:$1048576
- Stop If True ไม่ถูกเลือก

โค้ดที่จัดทำตามการตีความจากภาพ:
- เซลล์ไม่ว่าง: เส้นขอบล่างสีดำ แบบทึบ ความหนา Thin
- เซลล์ว่าง: เส้นขอบล่างสีเทาอ่อน แบบจุด ความหนา Thin
- ใช้กับ ActiveSheet.Cells
- ไม่ลบ Conditional Formatting เดิมก่อนเพิ่ม เพื่อไม่ทำลายกฎของผู้ใช้
- StopIfTrue = False
- แสดง MsgBox เมื่อเพิ่มกฎเรียบร้อย

วิธีใช้:
1. Import Format_Blank_NonBlank.bas เข้า VBA Project
2. เปิด Sheet เป้าหมาย
3. รัน ApplyBlankNonBlankFormatting หนึ่งครั้ง

ข้อควรระวัง:
- ถ้ารันซ้ำ จะเพิ่มกฎซ้ำ เพราะตั้งใจไม่ลบกฎเดิมโดยอัตโนมัติ
- มี Macro DeleteAllConditionalFormattingFromActiveSheet แต่ต้องยืนยันก่อนลบ
- Macro ลบจะลบ Conditional Formatting ทุกกฎใน Active Sheet
- รูปภาพไม่ได้แสดง Format Details ครบถ้วน การเลือกเส้นทึบ/เส้นจุดจึงเป็น
  สมมติฐานที่ใช้สร้างเวอร์ชันแรก หากผู้ใช้ต้องการสีหรือเส้นอื่นให้แก้ตามคำสั่ง
