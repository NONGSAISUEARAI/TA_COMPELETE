# CUTTING_LIST — ฟังก์ชัน VBA จัดแผนตัด

นำเข้า `A_FUNC_CUTTING_LIST.bas` ผ่าน Alt+F11 → File → Import File แล้วบันทึกสมุดงานเป็น `.xlsm` เปิดใช้แมโครตามการตั้งค่าของเครื่อง ใช้ Excel ที่รองรับ Dynamic Array เพื่อให้ผลลัพธ์ขยายจากเซลล์สูตร

## สูตรและ Argument

```excel
=CUTTING_LIST(DataRange,StockLength,Kerf,[TrimStart],[TrimEnd],[MinReusable],[MixGroups])
```

วงเล็บ `[]` ใช้แสดง Argument ที่ไม่จำเป็น ไม่ต้องพิมพ์ลงในสูตรจริง

| Argument | ความหมาย | ค่าเริ่มต้น |
|---|---|---|
| DataRange | ช่วงเซลล์จริง รวมหัวกลุ่ม หัวรหัสวัสดุ ความยาว และจำนวน | ต้องระบุ |
| StockLength | ความยาวเส้นวัตถุดิบ หน่วย มม. | ต้องระบุ |
| Kerf | รอยเลื่อยต่อชิ้น หน่วย มม. | ต้องระบุ |
| TrimStart | ระยะเผื่อตัดแต่งหัวเส้น รวมเนื้อที่เสียจากการแต่งหัว | 0 |
| TrimEnd | ระยะเผื่อตัดแต่งท้ายเส้น รวมเนื้อที่เสียจากการแต่งท้าย | 0 |
| MinReusable | เศษยาวขั้นต่ำที่จัดเป็นเศษเก็บใช้ต่อ | 0 |
| MixGroups | TRUE รวมต่างกลุ่ม P ได้เฉพาะรหัสวัสดุตรงกัน; FALSE แยกตามกลุ่ม | FALSE |

Argument ตัวเลขอ้างอิงเซลล์ตั้งค่าได้ เช่น `=CUTTING_LIST(DATA!A1:E20,B1,B2,B3,B4,B5,B6)`

## รูปแบบข้อมูลตามภาพ

ตัวอย่างวางใน `DATA!A1:E5`:

| เซลล์/แถว | A | B | C | D | E |
|---|---|---|---|---|---|
| 1 | Group | P17 | (ว่าง) | P18 | (ว่าง) |
| 2 | Length | S2214V | SD-9211 | S2214V | SD-9211 |
| 3 | 1600 | 3 | 0 | 1 | 0 |
| 4 | 2200 | 1 | 0 | 1 | 0 |
| 5 | 2800 | 0 | 1 | 0 | 1 |

- คอลัมน์แรกของช่วงที่เลือกเป็นความยาว ไม่จำเป็นต้องเป็นคอลัมน์ A ของชีต
- แถวก่อนความยาวตัวแรกเป็นรหัสวัสดุ และแถวเหนือรหัสเป็นกลุ่มงาน ถ้ามีเพียงหัวรหัสแถวเดียวก็ใช้ได้ โดยกลุ่มจะว่าง
- หัวกลุ่มเว้นช่องซ้ำหรือ Merge แนวนอนได้ โดยต้องเลือกครอบคลุมเซลล์ซ้ายสุดที่มีชื่อกลุ่มด้วย
- แต่ละคอลัมน์จำนวนต้องมีรหัสวัสดุของตัวเอง ห้าม Merge รหัสข้ามหลายคอลัมน์ที่มีจำนวน
- ความยาวต้องเป็นเลขบวก จำนวนเป็นจำนวนเต็มตั้งแต่ 0 ขึ้นไป ช่องว่างและสูตรที่คืน `""` ในช่องจำนวนจะถูกข้าม ตัวเลขที่เก็บเป็นข้อความใช้ได้
- อย่าเลือกแถวชื่อเรื่อง แถวรวม หรือท้ายตารางเข้ามาด้วย แถวว่างล้วนภายใน/ท้ายช่วงเลือกได้
- รหัสวัสดุเทียบแบบไม่แยกตัวพิมพ์เล็ก–ใหญ่ ต้องแยกรหัสให้ครบคุณสมบัติที่ห้ามตัดร่วมกัน เช่น สี ผิว หรือเกรด

สูตรตัวอย่าง:

```excel
=CUTTING_LIST(DATA!A1:E5,6000,3,10,10,300,TRUE)
```

สูตรสั้น ใช้ค่าตั้งต้นของ Argument เสริม:

```excel
=CUTTING_LIST(DATA!A1:E5,6000,3)
```

ผลลัพธ์ตัวอย่างแรกใช้ S2214V 2 เส้น และ SD-9211 1 เส้น รวม 3 เส้น จำนวนชิ้นรวม 8 ชิ้น ชิ้นงานรวม 16,400 มม. รอยเลื่อย 24 มม. ตัดแต่งหัว–ท้าย 60 มม. เศษรวม 1,516 มม.

## Dynamic หมายถึงอะไร

จำนวนกลุ่ม รหัสวัสดุ แถวความยาว และจำนวนชิ้นไม่ถูกล็อกในโค้ด แต่ฟังก์ชันจะอ่านเฉพาะเซลล์ใน `DataRange` เท่านั้น เมื่อเพิ่มข้อมูลต้องขยายช่วงอ้างอิงให้ครอบคลุม หรือใช้ Named Range ที่ขยายได้ ถ้าตารางต้นทางมาจากสูตร Spill ใช้ `DATA!A1#` ได้

`CutData` เป็นเพียงชื่อช่วงที่ผู้ใช้ตั้งเอง ไม่ใช่ชื่อที่โค้ดสร้างให้อัตโนมัติ ไม่ควรเลือกทั้งคอลัมน์ เนื่องจากจะอ่านเซลล์จำนวนมาก

## ฟอร์มรายงานตามแนว PACK_SUMMARY_v2_7

สูตรและ Argument ทั้ง 7 ตัวคงเดิม ผลลัพธ์เป็น Array ที่ขยายความกว้างตามจำนวน Item จัดเป็นรายงาน 4 ส่วนต่อกันในแนวตั้ง ไม่ต้องเรียกฟังก์ชันสรุปเพิ่ม:

1. **SUMMARY REPORT** — สรุปความยาววัตถุดิบที่ใช้ ความยาวชิ้นงานที่ตัด ความยาวที่ต้องการ จำนวนเส้น จำนวนชิ้นต้นทาง/ตัดแล้ว/คงเหลือ รอยเลื่อย ตัดแต่ง เศษรวม เศษเก็บใช้ต่อ และเศษทิ้ง
2. **Target used list** — สรุปเส้นวัตถุดิบที่ใช้แยกตามรหัสวัสดุและกลุ่ม พร้อมจำนวนเส้น ความยาวรวม ความยาวชิ้นงาน รอยเลื่อย ตัดแต่ง เศษ และเปอร์เซ็นต์เศษ ถ้ารวมหลายกลุ่ม P จริงจะแสดง `MIXED`
3. **Item used list** — เทียบ `Source Qty / Used Qty / Remaining` แยกตามวัสดุ กลุ่ม P และความยาว พร้อมความยาวรวมต้นทางและที่ตัดแล้ว ข้อมูลความยาวซ้ำภายในวัสดุ/กลุ่มเดียวกันจะรวมจำนวน
4. **CUTTING PLAN** — แผนตัดรายเส้น แยกความยาวแต่ละชิ้นเป็นตัวเลขใน `Item1…ItemN` แล้วต่อท้ายด้วยข้อมูลรวมชิ้นงาน รอยเลื่อย ตัดแต่ง เศษเหลือ เปอร์เซ็นต์ใช้เนื้อ และประเภทเศษ

ส่วนสรุปและช่อง Remaining ใช้ค่าว่างแทนศูนย์ตามแนวตัวอย่าง ช่องว่างนี้หมายถึง 0 ไม่ใช่ข้อมูลขาด ส่วนตัวเลขรอยเลื่อย ตัดแต่ง และเศษในแผนตัดรายเส้นยังแสดง 0 เพื่อให้ตรวจสมดุลได้

เปอร์เซ็นต์ทุกส่วนเป็นตัวเลข **0–100** เช่น `8.42` หมายถึง 8.42% ใช้รูปแบบเซลล์เป็น Number ไม่ต้องใช้ Percentage ซึ่งจะคูณ 100 ซ้ำ

ตารางสรุปเริ่มด้วย:

| รายการ | ตัวอย่าง |
|---|---:|
| SUMMARY REPORT | |
| Stock Total (mm) | 18000 |
| Used Total (mm) | 16400 |
| Required Total (mm) | 16400 |
| Bars Used | 3 |
| Source Qty | 8 |
| Used Qty | 8 |
| Remaining Qty | (ว่าง = 0) |
| Kerf Total (mm) | 24 |
| Trim Total (mm) | 60 |
| Gap Total (mm) | 1516 |
| Gap Total (%) | 8.42 |
| Reusable Total (mm) | 1516 |
| Scrap Total (mm) | (ว่าง = 0) |

`Used Total` คือเนื้อชิ้นงานเท่านั้น `Gap/Total Waste` คือเศษปลายเส้นหลังหักรอยเลื่อยและตัดแต่งแล้ว จึงแสดงรอยเลื่อยและตัดแต่งเป็นรายการแยก ไม่รวมซ้ำเข้า Gap

## คอลัมน์ของ CUTTING PLAN

| คอลัมน์ | ความหมาย |
|---|---|
| Material | รหัสวัสดุ |
| Group | กลุ่มงานของเส้นนี้ ถ้าชิ้นในเส้นมาจากหลายกลุ่มจะแสดง MIXED |
| Bar | ลำดับเส้น เริ่มใหม่เมื่อเปลี่ยนชุดวัสดุ/กลุ่มที่แยกตัด |
| Stock (mm) | ความยาวเส้นวัตถุดิบ |
| Item1…ItemN | ความยาวชิ้นงาน หนึ่งชิ้นต่อหนึ่งเซลล์ เป็นตัวเลขที่นำไป SUM ได้ ความยาวซ้ำแยกคนละช่อง |
| Group cuts | รายละเอียดกลุ่มและชิ้น เช่น `P17: 2200 x 1 + P18: 2200 x 1` |
| Pieces | จำนวนชิ้นในเส้นนี้ |
| Cut total (mm) | ผลรวมความยาวชิ้นงาน |
| Kerf loss (mm) | จำนวนชิ้น × รอยเลื่อย |
| Trim loss (mm) | TrimStart + TrimEnd |
| Remainder (mm) | ความยาวเศษหลังหักชิ้นงาน รอยเลื่อย และตัดแต่ง |
| Used (%) | 100 × Cut total / Stock เป็นตัวเลข 0–100 |
| Remnant | NONE = ไม่มีเศษ; REUSABLE = เศษถึงเกณฑ์; SCRAP = เศษต่ำกว่าเกณฑ์ |

คอลัมน์ท้ายสุด 6 ช่องเรียงเป็น **Cut total (mm) / Kerf loss (mm) / Trim loss (mm) / Remainder (mm) / Used (%) / Remnant** เสมอ ตำแหน่งจะเลื่อนตามจำนวน Item

ตัวอย่างจากข้อมูลข้างต้น หมวด 4 จะมี Item สูงสุด 3 ช่อง:

| Material | Group | Bar | Stock (mm) | Item1 | Item2 | Item3 | Group cuts | Pieces | Cut total (mm) | Kerf loss (mm) | Trim loss (mm) | Remainder (mm) | Used (%) | Remnant |
|---|---|---:|---:|---:|---:|---:|---|---:|---:|---:|---:|---:|---:|---|
| S2214V | MIXED | 1 | 6000 | 2200 | 1600 | 1600 | P17: 2200 x 1 + P18: 1600 x 1 + P17: 1600 x 1 | 3 | 5400 | 9 | 20 | 571 | 90 | REUSABLE |
| S2214V | MIXED | 2 | 6000 | 2200 | 1600 | 1600 | P18: 2200 x 1 + P17: 1600 x 2 | 3 | 5400 | 9 | 20 | 571 | 90 | REUSABLE |
| SD-9211 | MIXED | 1 | 6000 | 2800 | 2800 | | P17: 2800 x 1 + P18: 2800 x 1 | 2 | 5600 | 6 | 20 | 374 | 93.333333… | REUSABLE |

`N` เท่ากับจำนวนชิ้นมากที่สุดในหนึ่งเส้นของแผนที่เลือก ไม่มีการล็อกไว้ที่ 4 หรือ 40 ช่อง แถวที่มีชิ้นน้อยกว่าจะเว้น Item ส่วนเกินเป็นค่าว่าง เมื่อไม่มีรายการจะยังมีหัว Item1

ความกว้างรายงาน = **12 + N คอลัมน์** เช่น ตัวอย่างนี้มี 15 คอลัมน์ ส่วนสรุปและตารางเทียบด้านบนยังใช้คอลัมน์เดิม ส่วนที่เกินเป็นค่าว่าง ต้องเผื่อพื้นที่ Spill ทั้งด้านขวาและด้านล่าง เมื่อข้อมูลเปลี่ยนจน N เปลี่ยน ความกว้างรายงานจะเปลี่ยนด้วย

ไม่มีความต้องการตัดจะคืนหัวรายงาน สรุปค่าว่างแทนศูนย์ และหัวตารางทั้ง 3 ส่วน โดยไม่มีแถวรายการ เมื่อ `MinReusable=0` เศษบวกทั้งหมดจะเป็น REUSABLE

ก่อนคืนรายงาน ฟังก์ชันเทียบจำนวนที่จัดตัดจริงกับต้นทางทุกวัสดุ/กลุ่ม/ความยาว ถ้าจำนวนไม่ตรงจะคืน error ทั้งแผน

## วิธีคำนวณและขอบเขตรุ่นแรก

ลองจัดสองแผน: เรียงชิ้นยาวก่อน และเรียงสลับชิ้นยาว–สั้น แต่ละแผนเลือกลงเส้นที่เหลือพื้นที่น้อยที่สุดหลังเพิ่มชิ้นนั้น แล้วเลือกแผนที่ใช้จำนวนเส้นน้อยกว่า ถ้าเท่ากันใช้แผนเรียงยาวก่อน เป็นวิธีประมาณคำตอบ ไม่รับรองจำนวนเส้นต่ำสุดทุกกรณี การจัดเรียงและผลลัพธ์เหมือนเดิมเมื่อข้อมูลเดิม

นับรอยเลื่อย **หนึ่งครั้งต่อชิ้น รวมชิ้นสุดท้าย** เช่น ชิ้นยาว 6000 มม. ไม่สามารถตัดจากเส้น 6000 มม. เมื่อรอยเลื่อยเป็น 3 มม. หากเครื่องจริงมีเงื่อนไขใช้ปลายเส้นโดยไม่เสียรอยเลื่อย ต้องปรับแบบจำลองก่อนใช้งานตามเงื่อนไขนั้น

ตรวจสมดุลแต่ละเส้นได้จาก:

```text
Stock = Cut total + Kerf loss + Trim loss + Remainder
```

การตัดแต่งเป็นระยะรวมที่เสียหัว–ท้าย ไม่บวกรอยเลื่อยแต่งหัว–ท้ายซ้ำให้อีก เศษที่เป็นศูนย์ภายในค่าคลาดเคลื่อนการคำนวณจะปัดเป็น 0

ความยาววัตถุดิบเดียวใช้กับทุกรหัสในหนึ่งสูตร สมมติมีวัตถุดิบเพียงพอ ยังไม่จำกัดจำนวนสต็อก ไม่ใช้เศษเดิมกลับมาตัด และไม่ได้จัดหาเศษให้ถึงเกณฑ์ `MinReusable` ซึ่งใช้แค่จัดประเภทเศษ

ฟังก์ชันอ่านข้อมูลแล้วคืน Array เท่านั้น ไม่เขียนชีตอื่น ไม่เปลี่ยนข้อมูลเดิม และไม่ต้องกดปุ่ม

## ข้อผิดพลาด

| ผลลัพธ์ | สิ่งที่ต้องตรวจ |
|---|---|
| #VALUE! | Argument ติดลบ/ไม่ถูกต้อง ตัดแต่งจนไม่เหลือพื้นที่ รอยเลื่อยกินพื้นที่ทั้งหมด หัวตารางขาด ความยาวผิด จำนวนติดลบ/ทศนิยม หรือข้อมูลมี Excel error |
| #REF! | ช่วงข้อมูลหลายพื้นที่ ให้เลือกสี่เหลี่ยมต่อเนื่องหนึ่งช่วง |
| #NUM! | ชิ้นงานรวมรอยเลื่อยยาวเกินเส้น ข้อมูล/ผลลัพธ์เกินขีดจำกัด หรือคำนวณล้น |
| #SPILL! | เคลียร์พื้นที่ด้านขวาตามจำนวนคอลัมน์จริง (12 + N) และแถวด้านล่างสูตร รวมเซลล์ Merge ที่กีดขวาง และวางสูตรนอก Excel Table |
| #NAME? | ตรวจว่านำเข้าโมดูลแล้ว และเปิดใช้ VBA/UDF |

จำกัด 2,000,000 เซลล์ต้นทาง, 2,000,000 เซลล์ผลลัพธ์ทั้งรายงาน, 20,000 ชิ้นรวม, 20,000,000 ครั้งในการตรวจช่องว่างเส้น และข้อความไม่เกิน 32,767 ตัวอักษรต่อเซลล์ จำนวนคอลัมน์รวมต้องไม่เกินขอบเขต Excel และพื้นที่จากเซลล์สูตรถึงขอบชีต ถ้าเกินจะคืน error ทั้งแผน ไม่ตัดคอลัมน์ Item หรือคืนแผนที่ขาดชิ้นงาน
