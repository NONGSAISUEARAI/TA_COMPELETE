# ข้อมูลสำหรับ create_rfq.py

JSON ระดับบน:

| ฟิลด์ | ความหมาย |
| --- | --- |
| `headers` | หัวเอกสารตามรายการด้านล่าง; ต้องมี `documentNo` |
| `rows` | รายการตารางหลักตามลำดับ แบ่ง 20 รายการต่อหน้า |
| `secondary` | รายการตารางล่าง แยกเป็นอาร์เรย์ต่อหน้า สูงสุด 11 รายการต่อหน้า |
| `materialName` | ชื่อวัสดุสำหรับตั้งชื่อไฟล์ |
| `fileName` | ฐานชื่อไฟล์กำหนดเอง ไม่ใส่นามสกุล; ไม่ใส่จะตั้งชื่ออัตโนมัติ |
| `pageCount` | จำนวนหน้าขั้นต่ำ เช่น ต้องการหน้าว่างท้ายเอกสาร |
| `checks` | ค่ากล่องติ๊กเริ่มต้นทุกหน้า; ค่าที่ไม่ส่งเป็น `false` |
| `pageChecks` | อาร์เรย์ object ค่าติ๊กทับเฉพาะแต่ละหน้า |

`headers`: `documentNo`, `job`, `project`, `customer`, `dueDay`, `dueMonth`, `dueYear`, `requester`, `requestDate` (`pageNumber` ตัวช่วยคำนวณเอง) ส่งวันที่ในรูปแบบที่ผู้ใช้ยืนยัน ห้ามเดากำหนดส่งเอง

`checks` และ `pageChecks` ใช้ Boolean เท่านั้น:
`quote`, `production`, `ceiling`, `sunshade`, `wall`, `other`, `inside`, `outside`

## ฟิลด์ในแต่ละแถว

| คีย์ | ช่องในฟอร์ม |
| --- | --- |
| `no` | ลำดับ; ตัวช่วยเขียนใหม่ตามแถว |
| `description` | รายการ / รหัสชิ้นงาน |
| `materialCode` | รหัสตามตารางในฟอร์ม ส่งเป็น string |
| `material` | อ่านจากรหัสอัตโนมัติ; ไม่ต้องส่ง |
| `thickness` | ความหนา |
| `special` | วัสดุ/ความหนาพิเศษ หรือข้อมูลจัดซื้อ |
| `width`, `height`, `length` | ขนาดชิ้นงาน mm. |
| `cc`, `sp`, `pc`, `acp`, `otherCoat` | ช่องสีมาตรฐานแต่ละประเภท |
| `specialColor`, `paintType`, `brand` | รหัสสีพิเศษ ชนิดสี ยี่ห้อ |
| `sides` | ด้านที่พ่นสี เช่น `1 ด้าน` เมื่อมีข้อมูลยืนยัน |
| `qty` | จำนวน; number หรือข้อความตัวเลขมี comma ได้; ไม่ทราบใช้ `""` |
| `unit` | หน่วยตามข้อมูลต้นทาง |
| `cost` | ราคาต้นทุนต่อหน่วยเมื่อมีข้อมูล |
| `remark` | หมายเหตุ/รหัสอ้างอิงตามที่ผู้ใช้ระบุ |

ค่าที่ไม่ส่งจะว่าง ตัวช่วยไม่รวมแถว ไม่แยกสี ไม่คำนวณขนาดจากชื่อชิ้นงาน และไม่เติมราคา/จำนวน/หน่วยให้เอง

ตัวอย่างโครงสร้างเท่านั้น ค่าในตัวอย่างไม่ใช่ข้อมูลสำหรับใบจริง:

```json
{
  "headers": {
    "documentNo": "BU2-DE-26xxx",
    "project": "ชื่อโครงการจากผู้ใช้",
    "job": "",
    "customer": ""
  },
  "materialName": "ชื่อวัสดุจากผู้ใช้",
  "checks": {"quote": true},
  "rows": [
    {
      "description": "รายการจากข้อมูลที่ยืนยัน",
      "materialCode": "1",
      "thickness": "1.2",
      "qty": "",
      "unit": "ชิ้น"
    }
  ]
}
```
