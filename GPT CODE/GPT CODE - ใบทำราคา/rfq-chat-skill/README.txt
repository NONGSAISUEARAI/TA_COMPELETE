- CSV ตัวอย่างมีฟิลด์ TTL_PJ_NO, TTL_PJ_NAME_, TTL_PJ_PART-CODE, TTL_PJ_PART-NAME, TTL_PJ_MATTERIAL, TTL_PJ_SPEC, TTL_PJ_THK, TTL_PJ_FINISH_1/2, และเลข Drawing
