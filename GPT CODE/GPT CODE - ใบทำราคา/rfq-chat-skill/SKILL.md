# ใบขอราคาวัสดุสั่งทำพิเศษ

ขอบเขตความรู้นี้มาจากแชตนี้เท่านั้น ตัวอย่างไฟล์และรหัสในแชตเป็นข้อมูลประกอบ ไม่ใช่ค่าคงที่ของงานใหม่ ตรวจไฟล์ต้นทางและไฟล์ล่าสุดจริงทุกครั้งก่อนทำงาน อย่าเดาจำนวน สี JO หรือรายละเอียดที่ CSV ไม่ระบุ

## ลำดับเอกสารและหัวฟอร์ม

- ตรวจเลขปกติ `BU2-DE-26xxx` ในโฟลเดอร์ `Z:\B2_EXTERNAL\BACK UP PROJECT WORKS\5. งานแบบdrawing\6. ใบขอราคา\2569` ก่อนออกเลขใหม่ นับ `REVxx` เป็นฉบับแก้ไขของเลขเดิม ไม่ใช่เลขถัดไป ณ 28 ต.ค. 2569 เลขปกติสูงสุดที่ตรวจในแชตคือ `BU2-DE-26098`; งาน C10 ใช้ `BU2-DE-26099` แล้ว ดังนั้นห้ามสมมติว่าเลขต่อไปยังเป็น 26099
- เลขที่ใบขออยู่ `Z1`; JO อยู่ `Z2`; ชื่อโครงการอยู่ `C2`; ชื่อลูกค้าอยู่ `C3`; วันที่กำหนดใน `V3`, `W3`, `X3` ตามลำดับวัน/เดือน/ปี พ.ศ. สองหลัก
- เมื่อสั่งทำวันนี้ วันที่กำหนดคือวันปัจจุบันตามเวลาไทยบวก 14 วัน ต้องคำนวณใหม่ ไม่คัดลอกวันที่ตัวอย่าง
- หนึ่งชีทใส่ได้ไม่เกิน 20 รายการ ถ้าเกินให้เพิ่มชีทที่คงฟอร์มมาตรฐานและช่องติ๊กเดิม; `Z45` แสดงหน้าปัจจุบัน/จำนวนหน้าทั้งหมด
- ตั้งชื่อ Excel ตาม `BU2-DE-26xxx - ชื่อโครงการ_YYYYMMDD-HHMM.xlsm` (ผู้ใช้ยอมรับ `.xlsm`; `.xlsx` ได้เมื่อเหมาะกับฟอร์ม) และทำ PDF ด้วยเมื่อสั่งทำใบขอราคาตาม workflow นี้ บันทึกในที่อยู่ใบขอราคาที่ผู้ใช้กำหนด โดยไม่ทับไฟล์เดิมโดยไม่ตรวจ

## อ่าน CSV และลงรายการ

- ใช้ `TTL_PJ_NO` เพื่อยืนยัน JO, `TTL_PJ_NAME_` เป็นชื่อโครงการ, `TTL_PJ_PART-NAME` กับ `TTL_PJ_PART-CODE` รวมในคอลัมน์ `B` ในรูป `ชื่อ / รหัส`, `TTL_PJ_THK` ลง `I` เป็นตัวเลขมิลลิเมตร, และระบุขนาด `K` กว้าง / `M` ยาวจากรหัสชิ้นงาน ไม่เอาเลขหน้า Drawing ไปใส่รายการ
- รหัส `ACOUS-STD` และ `ACOUS-VAR` ใช้เลขต้นรหัสเป็นความกว้างและเลขต่อจากนั้นเป็นความยาว เช่น `3001800...` คือ 300 × 1800 มม. `ACOUS-VAR-xxx` ใช้เลข `xxx` เป็นความกว้าง ส่วนความยาวเดิม เช่น `3001825...VAR-300` คือ 300 × 1825 มม. เมื่อแก้รหัสชิ้นงาน `VAR-xxx` ให้เลขต้นรหัสตรงกับ `xxx` ด้วย โดยคงส่วนท้ายเดิม
- สำหรับ `Alu.hook on Panel` ที่ความยาวต่ำกว่า 900 มม. เปลี่ยน `/PF-S/` เป็น `/NON-PF-S/` ตามที่ผู้ใช้กำหนด; รายการที่ยาวตั้งแต่ 900 มม. คงเดิม ตรวจรูปแบบรหัสแต่ละชุดก่อนนำกฎนี้ไปใช้
- `1100 H14` ไม่ลง `J`; ใช้ร่วมกับวัสดุ/finish กำหนดรหัส `E`: อะลูมิเนียม 1100 H14 แบบ mill finish ไม่มีรหัสสี = 1 หรือ 2 ตามเงื่อนไขวัสดุในตาราง `E51:G86`; one side paint มีรหัสสี = 3; two side paint มีรหัสสี = 4 ตรวจผลที่ `G` ซึ่งผูกกับ `E`
- `SD-9103` เป็นสีมาตรฐาน ลง `P` เป็น `SD-9103`; `T` และ `U` ว่าง สีพิเศษ เช่น `NS-1S-P0070`, `NS-1S-E0114`, `S5206TH`, `SW255TH` ลง `S`; `T` = `PE or PC`; `U` = `Cornel` สำหรับ `NS-1S-*`, `Akzo Nobel` สำหรับ `S5206TH`/`SW255TH` ตรวจรหัสใหม่ก่อนจัดประเภท
- `ONE SIDE PAINT` ระบุพ่นสี 1 ด้านใน `V`; จำนวนลง `W` เมื่อมีข้อมูลจริง; หน่วยลง `X`; หมายเหตุลง `Z` เป็นเพียง `PPxx` ตามข้อมูลที่ยืนยัน ไม่เติม `DWG: xx` หรือ `TZP`
- สำหรับชุดที่เคยตกลงให้เรียงสี: `SW255TH` (PP17), `S5206TH` (PP17), `NS-1S-E0114` (PP18), `NS-1S-P0070` (PP19), `SD-9103` (PP20) แล้วเรียงมิติที่ผู้ใช้ระบุภายในสี คำสั่งเรียงเฉพาะงานหนึ่งไม่ใช่กฎสากลของทุก CSV

## ตรวจและส่งงาน

- ตรวจจำนวนแถวกับ CSV, รหัส, ความกว้าง/ยาว, สี, JO, วันที่, หน้า, สูตรที่ผูก `E`/`G`, ฟอร์มและช่องติ๊ก แล้วตรวจภาพ PDF ทุกหน้าที่มีเนื้อหา
- ถ้า CSV ไม่มีจำนวน ให้เว้น `W` และบอกผู้ใช้ชัดเจนว่าเป็นร่างรอจำนวน ไม่กรอกศูนย์แทน
- เมื่อต้องส่งขออนุมัติ ใช้ข้อความขึ้นต้นแนว `เรียนคุณ @mongkol ขออนุมัติใบขอราคาวัสดุสั่งทำพิเศษ โครงการ BU2-DE-26xxx - [ชื่อโครงการ]` แล้วแนบเอกสารที่เกี่ยวข้องตามจริง
- การแก้ PDF ที่ลงลายเซ็นดิจิทัลแล้วต้องสร้างฉบับแก้ไขแยกและให้ผู้มีสิทธิ์ลงนามใหม่ ภาพลายเซ็นหรือไดคัทไม่ใช่ลายเซ็นดิจิทัล และไม่ควรใช้แทนการอนุมัติฉบับแก้ไข
