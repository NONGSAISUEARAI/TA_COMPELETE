### TRAY-LT VARIES: แปลง GROUP SIZE

ใช้กับ source block งาน recessed-light ทั้ง STANDARD-SHAPE และ START-END_VARIES-SHAPE ชื่อ block จริงต้องตรงต้นทาง รวม _ และ - แต่ไม่ใช้ชื่อ block ยาวเป็น Part Name ปลายทาง

ข้อมูล `BLOCK NAME,W1,W2,FINISH` มีความหมายดังนี้:

- W1 = ระยะจากขอบด้านแรกถึง CENTER; W2 = ระยะจาก CENTER ถึงอีกขอบ
- ความกว้างถาด W = 249 มม.; ความยาว L = W1 + W2
- W1 และ W2 ไม่ใช่กว้าง × ยาว ห้ามนำ W1 ลง K หรือใช้ W2 เป็น M โดยตรง ห้ามสลับ W1/W2

ช่องรายการ/รหัสชิ้นงานไม่ใช้ Wrap Text ให้แสดงชื่อและ `(PART CODE)` ต่อกันในบรรทัดเดียวตามหัวข้อการตั้งชื่อ ลดขนาดข้อความหรือใช้ Shrink to Fit เมื่อเกินช่อง หากยังไม่พออนุญาตให้ขยายช่องได้ ตรวจ PDF ว่าอ่านได้และไม่ตัดข้อความ

ความสูงแถวรายการช่องที่ 1-20 ของแต่ละหน้า (แถว Excel 7:26) ใช้ 17 พอยต์ รวมแถวว่างที่เหลือในหน้าสุดท้าย ไม่เปลี่ยนความสูงหัวตารางหรือส่วนอื่น
