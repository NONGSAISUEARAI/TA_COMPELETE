# TA 3D UNFOLD — รุ่นทดลองสำหรับโปรไฟล์อลูมิเนียมพับ

คำสั่ง `TA3DUNFOLD` คลี่ `3DSOLID` ที่เป็นแผ่นความหนาคงที่และมีแนวพับทุกแนวขนานกัน
ออกเป็นกรอบ 2D พร้อมเส้นพับ โดยเก็บ Solid ต้นฉบับไว้ครบ

## การติดตั้งและใช้งาน

1. รัน `build.ps1` ด้วย PowerShell 7 เพื่อสร้าง `TA_3D_UNFOLD.dll` โดยสคริปต์จะคัดลอก DLL มาวางข้าง `3D_UNFOLD.lsp` ให้อัตโนมัติ
2. เพิ่มโฟลเดอร์นี้ใน `TRUSTEDPATHS` ของ AutoCAD
3. ตรวจว่า `3D_UNFOLD.lsp` และ `TA_3D_UNFOLD.dll` อยู่ในโฟลเดอร์เดียวกัน แล้ว `APPLOAD` ไฟล์ `3D_UNFOLD.lsp`
4. เรียก `TA3DUNFOLD`
5. เลือก Solid แล้วระบุความหนา, รัศมีพับด้านใน, K-factor และจุดวางแบบคลี่

คำสั่ง `TA3DINSPECT` วิเคราะห์ Solid อย่างเดียวและไม่สร้างวัตถุ

## ขอบเขตรุ่นแรก

- AutoCAD 2026 x64 / .NET 8
- Solid ต้องเป็นโปรไฟล์ตรง หน้าตัดคงที่ และไม่มีรู/บากตามแนวยาว
- รองรับแผ่นพับเป็นสายเดียวและแนวพับขนานกัน
- ค่าเริ่มต้น K-factor = 0.33 และรัศมีด้านใน = ความหนา
- สร้างเส้นขอบในเลเยอร์ `TA_UNFOLD_OUTLINE` และเส้นพับใน `TA_BEND_LINE`
- ยังไม่รองรับแนวพับคนละแกน, ผิวโค้งอิสระ, กิ่งแยก, งานม้วน หรือชิ้นงานที่ความหนาไม่คงที่

ผลลัพธ์เป็นการคำนวณแบบงานพับจากหน้าราบและค่ารัศมี/K-factor ที่ผู้ใช้กำหนด
ควรตรวจขนาดกับตาราง Bend Allowance ของเครื่องพับก่อนส่งผลิตจริง
