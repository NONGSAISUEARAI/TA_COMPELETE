2. Layer Filter / Group Filter
============================================================

ศึกษาการอ่าน Layer Filter Folder จากไฟล์:

C:\Users\tawan.t\Documents\GitHub\TA_COMPELETE\000 - FOR_CREATE_LAYER_.lsp

ส่วนที่ศึกษาประมาณบรรทัด 2460 ลงไป

ข้อสรุป:

- AutoLISP อ่านรายชื่อ Filter และ Group Filter ที่บันทึกใน DWG ได้
- ข้อมูลอยู่ใน Extension Dictionary ของ LayerTable ภายใต้ ACLYDICTIONARY
- ชื่อ Filter อ่านจาก DXF code 300
- Layer สมาชิกของ Group Filterอ้างอิงผ่าน DXF code 330
- Nested Filter เชื่อมผ่าน DXF code 360
- :LayerFilterList ใช้ List ชื่อ Filter รวม Sub Filter
- :grouplayerfilterswlayernames ใช้อ่าน Group Filter พร้อม Layer สมาชิกระดับบน
- AutoLISP ไม่มี API มาตรฐานสำหรับตรวจ Filter ที่กำลังไฮไลต์ใน Layer
  Properties Manager
- AutoLISP ไม่มี API มาตรฐานสำหรับสั่ง UI ให้เลือก Filter Folder
- สามารถเลือก Filter เชิงตรรกะภายในระบบ TA_COMPELETE แล้วนำรายชื่อ Layer
  ไปเปิด/ปิด, Freeze/Thaw หรือ Lock/Unlock ได้

ข้อควรระวัง:

- dictnext ใช้ iterator ร่วมกัน จึงไม่ควร recurse เข้า Dictionary ลูกทันที
- ควรเก็บรายการของ Dictionary แม่ให้ครบก่อน recurse

3. ปัญหาสี Dynamic Block ไม่อัปเดต
============================================================

ศึกษาจากไฟล์:

Z50_change_color_in_block_REV02_by_ยอดคะน้าเซียนซักแห้ง.lsp

อาการ:

- แก้สีภายใน Block Definition แล้ว Dynamic Block ยังแสดงสีเดิม
- สีเปลี่ยนหลังใช้ RESETBLOCK

สาเหตุ:

- Dynamic Block Reference แสดงผ่าน Anonymous Block Definition ชื่อ *U...
- ฟังก์ชันรวบรวม Block Name ตัดชื่อที่ขึ้นต้นด้วย * ออก
- Definition ต้นฉบับถูกแก้ แต่ anonymous representation ปัจจุบันไม่ได้ถูกแก้
- RESETBLOCK สร้าง representation ใหม่จากต้นฉบับ สีจึงปรากฏ

แนวทางแก้โดยไม่ RESETBLOCK:

- แก้ Definition ต้นฉบับตามเดิม
- เดิน Blocks collection แล้วอัปเดต Anonymous Block *U โดยตรงผ่าน VLA
- แก้ Color และ Dimension color overrides
- เรียก Update และ Regen

เหตุผลที่ไม่ควร RESETBLOCK อัตโนมัติ:

- อาจรีเซ็ต Stretch, Flip, Visibility, Lookup และค่าประจำ Reference

4. Local Variables และเครื่องหมาย / ใน DEFUN
============================================================

รูปแบบ:

(defun FunctionName (arguments / local-variables)
  ...
)

ความหมาย:

- ก่อน / คือ Parameters ที่ผู้เรียกต้องส่ง
- หลัง / คือ Local Variables
- Command ที่ขึ้นต้นด้วย c: ปกติไม่มี Parameter จึงเขียน:

(defun c:COMMAND_NAME (/ ss_ obj_ index_)
  ...
)

ตัวแปร Local ชื่อเดียวกันในหลาย defun ไม่ทับกัน หากทุกฟังก์ชันประกาศ
ตัวแปรนั้นหลัง / ของตัวเอง

AutoLISP ใช้ Dynamic Scope หากฟังก์ชันลูกไม่ประกาศตัวแปรเป็น Local
การ setq อาจแก้ Local Binding ของฟังก์ชันแม่ที่กำลังทำงานอยู่ได้

ค่าที่ต้องจำข้ามการเรียก Command ไม่ควรประกาศหลัง / และควรตั้งชื่อ Global
ให้ชัด เช่น *F113:PreviousInput*

- ใช้ตัวแปร Global input_hatch_scale เพื่อจำค่าครั้งก่อน
- ใช้ vla-put-PatternScale กำหนด Scale

9. SSGET สำหรับ Dynamic Block
============================================================

ssget ไม่มี DXF Group Code สำหรับตรวจ Dynamic Block โดยตรง

ขั้นแรกกรอง INSERT:

(ssget '((0 . "INSERT")))

จากนั้นตรวจผ่าน ActiveX:

(and
  (vlax-property-available-p block_obj_ 'IsDynamicBlock)
  (= :vlax-true
     (vla-get-IsDynamicBlock block_obj_)
  )
)

ไม่แนะนำให้ใช้ชื่อ *U อย่างเดียว เพราะ *U เป็น Anonymous Block Name และ
ไม่ใช่เงื่อนไขที่ยืนยัน Dynamic Block ได้ครบถ้วน

10. LM:getdynprops_nonvalue และ STRCASE
============================================================

LM:getdynprops_nonvalue คืน List ชื่อ Dynamic Properties โดยไม่คืน Values

ตัวอย่างผล:

("X" "Origin" "thk" "Origin" "Distance1" "Origin" "view")

แปลงเป็นตัวพิมพ์ใหญ่ด้วย lambda:

(mapcar
  '(lambda (property_name_)
     (strcase property_name_)
   )
  (LM:getdynprops_nonvalue
    ss_pre_filter_set_xx_obj_
  )
)

ผล:

("X" "ORIGIN" "THK" "ORIGIN" "DISTANCE1" "ORIGIN" "VIEW")

หากต้องการตรวจว่ามี Property หรือไม่ ใช้ member ได้:

(if (member "DISTANCE1" dynamic_property_list_)
  (prompt "\nFound DISTANCE1")
)
